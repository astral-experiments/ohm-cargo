# Whole-toolchain native checks on private and public Ruff edits

This plan freezes both inputs, both toolchains, the order and the acceptance criteria before any timing on the second host. Use the existing 16-vCPU Linux benchmark guest after its independent scheduler run has finished. Run the ordinary unqualified Ruff workspace check, with six build jobs and the same private registry, standard library, LLVM and linker in both arms. Write test patches only into bind-mounted overlays.

The control consists of the release-PGO Cargo at `461a3d1007ecc997a6d86c7d75e8b518575c8d90` and the release-PGO/BOLT compiler at `f1a7cf9d20b2cae39e991b178b56ba06b43dc8fa`. The candidate contains the nine Cargo drafts #242 through #250 and the compiler with #230, #231 and the check-only private trait impl change. Every crate, including registry dependencies, uses its own arm's compiler. Warm separate native checkpoints for the two arms. Before each observation, restore its arm's pre-edit state. Time `cargo +ohm check --locked --offline` with ordinary output, including the toolchain launcher and compiler children. Write one lightweight receipt per actual rustc. Outside timing, require a fully fresh 520-artifact verification command, the same feature and target graph, successful diagnostics and unchanged source and index. The expected compiler counts for the private edit are 35 and one. For the public edit they are 35 and 35. Disqualify any unexpected build or output instead of timing a different workload.

Each endpoint runs 12 pairs with six control-first and six candidate-first assignments. Shuffle the two schedules with seeds 814137 and 814138, then shuffle the interleaved pair labels with seed 814139. Save all 48 observations. Compute the median paired elapsed reduction, a distribution-free 95% median interval, and an exact two-sided randomization test across the 924 allowed orders. Adjust the two endpoint p-values with Holm. The public edit provides a negative control for accidental cutoff and its timing will be reported even if it is neutral.
