# Branch-return incremental compilation and external assembler inputs

Both compilers ran the same Cargo at revision `2d44bd4a` and used the same compiler frontend, standard library and linker. The parent compiler is `7e71d315`. The original branch-aware compiler is `a6865b6a`. With defaults disabled, it selected branch A’s older incremental session, reused the original byte value 17, and linked successfully with absent or malformed external assembler input. The parent, forced and empty builds returned 29 or rejected the invalid input. In default mode the compiler kept the native-input guard enabled and passed all three input classes.

Two real, committed branches have different complete Rust source bytes. Branch A reads a native byte through a nested assembler `.include` and `.incbin`. Branch B prints 43 and does not use the input. A initially prints 17. While on B, the experiment changes the byte to 29, removes it, or supplies a malformed assembler directive. It switches the actual linked worktree back to A and runs the compiler normally. The empty reference uses new target and build directories. The forced reference evicts the selected local incremental generation and target fingerprint; both references see the same source, external files, Cargo and compiler as the warm command.

The 90 ordinary default `cargo +ohm build` commands include independent `include_bytes!` and build-script-declared static archive controls. Each default altered-input program matched the entire forced and independently empty ELF; missing or malformed inputs failed. Another 30 builds isolated `cargo +ohm -Zohm-defaults=no build` for the assembler case. The recorded kernel calls identify which earlier dep-graph was actually copied, both native input opens and `ENOENT`, the compiler and link processes. Successful default links used the enrolled Wild; the opt-out's actual native chain used the system C driver, collect2 and ld.

`projection.json.gz` contains per-command exact raw-stream, argument-vector, full trace and whole-program SHA-256 commitments, real read/ENOENT events, branch-generation selection and forced-reference custody. The independent physical collector reopened every process trace, source and compressed ELF before this path-free projection. The small standalone replay used the same compiler, captured its own raw Cargo and executable streams, and recorded its ten build verdicts in `standalone.json`. Hashes of individual ELFs are comparable between warm/forced/empty *within a shared source path and compiler configuration*. This is a correctness check. No clock measurements were made.

Verify the released projection with `python3 -IB verify.py`. To exercise the standalone fixture on a Linux x86_64 +ohm toolchain in an unused private directory, run `python3 -IB reproduce.py "$PWD/branch-return-replay" --mode opt-out --expect stale`. The same script accepts `--mode default --expect correct` to exercise the default. The compiled program prints its observed native byte.
