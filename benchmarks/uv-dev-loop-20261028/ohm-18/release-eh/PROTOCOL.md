# Released Wild 0.11.0 unwind-writer comparison

The source question is whether `write_eh_frame_relocations` can share two initially empty values across a section and construct two offset diagnostics only on failure. The separate practical question is whether the resulting linker also improves the currently distributed Ohm. This registration fixes both controls before the first measurement. Earlier numbers came from the withdrawn #45 plus the original #46 and supply no samples here.

## Arms

All source builds use released Wild `e856d81f6683cad80b9fe0ebf1a0c3c403c6fe11`, its unchanged lockfile and the same Rust 1.99.1 compiler, absolute source path, target, flags and CPU allocation. Build the bare release first and require its executable to reproduce the already matched `82a927b8…` control. Apply only `eh.patch` to the same source using zero fuzz, rebuild, and freeze both executables before testing or sampling. The third control is Ohm 1.99.0-18’s distributed Wild, SHA-256 `0d633580…`. Its packaging differs from the matched release build. The treatment includes neither Wild PR, the jobserver retry, Cargo changes, Rust/library changes, PGO nor dependency updates.

Before admission, write a separate immutable input lock with source/plan/binary receipts, collector, counter, wrapper, oracle, source-edit and tool hashes. Bind executions to the explicit host-owner allocation. New binaries and the allocated CPU IDs are intentionally unknown at registration. Changing a source, input, endpoint or gate after inspecting scores requires an independent registration. Preserve every incomplete premeasurement or failed admission separately. No complete command runs before the entry gate and a new non-native allocation.

## Functional and captured-link entry gate

The direct-release candidate must pass every libwild unit test, the native x86-64 ELF repository groups eh-frame, eh-frame-terminator, crtend-only-eh-frame, dynsym-debug-eh-frame, relocation-overflow and backtrace (seven fixtures), plus the five fixed synthetic cases. Those cases include a valid header, valid output without a header, signed FDE-PC and frame-info-pointer overflows and an invalid CIE. Compare complete stderr, exit status and every successful output across all three executables.

Reuse the sealed, actual -18 `cargo test --no-run --locked --offline -j8` link captures 0 (181,196,328-byte uv lib harness) and 1 (316,558,984-byte uv executable). Both shapes have been studied previously on the old source. Each invocation uses the known original argv and inputs, the originally audited ELF interpreter, one fixed output slot, `--threads=1`, `--no-fork`, no inherited jobserver and the calibrated native user-instruction counter. The process is bound to one allocated CPU. The raw full-file SHA must match the stock one-worker oracle separately on each capture. There is no byte mask in this stage. Save every counter log, stderr, affinity, exact argv, input manifest and SHA.

Run the registered eight independently order-balanced pairs on each shape against each control. Intervals, orders and source inputs were fixed before building the direct candidate. Each control/shape cell separately requires eight lower counts out of eight, median fractional improvement of at least 0.10%, two-sided exact paired sign p ≤ .05 and two-sided balanced-order randomization p ≤ .05. For the latter enumerate all 70 assignments with four control-first pairs and use absolute mean signed log ratio. A failed completed cell, functional failure or unresolved roster/artifact mismatch ends qualification. Finish the valid complete cells already started and retain their raw rows. No sample replacement or pooled decision. As a descriptive control, report the 1 MB uvx test on the same single-worker mode in each six-position balanced shape once, with exact output/diagnostic parity required. Its count is reported separately without extra inferential claims.

## Complete Cargo command

The primary endpoint is the complete edited command's sum of user-mode instructions in the distributed -18 Cargo, every observed distributed -18 rustc, and every Wild process including its threads. The command is `cargo test --no-run --locked --offline -j8` on uv `c22e6b71933443e9cd299d4b6ac8de035ed4825b`. Use two independently settled private source trees with their own final Cargo-home, visibility and target paths. The structural source mutation is the same supported install-source predicate used to calibrate the actual edited-role harness. Arm-local state and source are restored after each study. The four independent pair schedules use distinct same-width source literal families, two cohorts × the two reference binaries. Every pair starts with identical source bytes, timestamps, full warm predecessor, tool paths and CPU allocation across its two arms.

In every cohort/comparator, four excluded admission cells run the same reserved edit from the same structural predecessor in native/count × control/candidate order. Trace `execve/execveat` in native mode with the normal linker fork, stock jobserver and flags. Counting changes only Wild fork mode to `--no-fork` for its calibrated PID-based parent/all-thread accounting. Require identical rustc argv multisets modulo wrapper and declared mode changes, all five Wild launches, every output path and all 72 test executables. The accepted steady roster is one Cargo, six rustc and five Wild processes. The raw counters must reconcile per PID and per thread and with the recently calibrated fork policy. Validate again on every scored invocation. Python, instrumentation, cc/collect2, kernel work and other processes are excluded. Admission native elapsed times supply no wall-time endpoint.

Save raw digests and sizes for all products. Four exact relative product paths have pre-existing released-Wild A/A proof for the two allowed `.rodata.sh_entsize` values (0 and 8) together with their 32-byte GNU build-id payload. Require byte equality outside precisely those fields and recognized field values. Every other product is byte-identical. The source-matched and distributed comparisons use this same rule. Abort on a new path, ELF difference or process roster. Do not widen exceptions after looking at a candidate.

Score eight pairs separately for each cohort/control, using the registered orders and source literals. Use the same signed improvement, median ≥0.10%, eight of eight wins, exact sign and balanced-order randomization p ≤.05 gates as for the captured links. A public whole-command improvement applies only if all four comparisons pass independently. When the matched comparison passes but the shipped one does not, report those as separate findings and withhold the whole-command qualification. A local counter result does not establish faster elapsed development time. A later wall decision would require separately registered, uncontended native trials. Schedule order is fixed in plan.json; interval tests/admissions and binary locks occur before scored work.
