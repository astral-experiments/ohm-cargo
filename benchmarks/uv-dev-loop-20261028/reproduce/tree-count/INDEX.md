# Edited uv role-sum evidence

`identical/summary.md` renders the admitted initial cohort and its conditional independent replication. `reproduce.md` describes the on-disk layout, frozen toolchain components and replay commands. The execution scopes are Cargo, all rustc invocations and all Wild invocations, summed by original PID across its threads. The paired native elapsed-time results in the main benchmark report cover the full command.

| Directory | Contents |
| --- | --- |
| `calibration/` | Known instruction deltas, inherited-descriptor check and deliberate exclusion of pre-exec work in forked children |
| `results/` | Rejected first structural-versus-literal pilot, including its exclusion and raw traces. Read `summary.md` for this pilot only |
| `identical/` | Registered primary protocol, four-cell same-input admission and eight new edited pairs per admitted endpoint |
| `replica/` | Prospective conditional repeat registration, exact shuffled schedules, qualification decisions and fresh eligible endpoint cohorts |

Each accepted native admission retains per-PID `exec.*` strace output and `native-execs.json`. Each counted invocation has its own recorded executable, argv, PID, thread counts and instruction total. The final statistics use the summed totals in each endpoint's `samples.csv`. Pilot values do not enter those estimates.
