# Whole-command native timing for all eight changes

This is a separate, prospective elapsed-time comparison of the self-trained Cargo drivers and the combined Wild changes. The endpoint is the full-workspace edited `cargo test --no-run --locked --offline -j8` on pinned uv. The previous seven-change measurements and all instruction studies remain distinct.

Both cohorts compile uv using the same released Ohm 1.99.0-17 rustc. Baseline Cargo is the independently self-trained `base` from `pgo-confirmation-v2` and Wild is the release-source baseline. Candidate Cargo is the independently self-trained `guard-stack`, containing the five Cargo changes and the standard-library change, and Wild `v2-wild` includes the cold undefined-diagnostic change and the prefix change. `plan.json` freezes the binary identities, actual private ELF slot, independent source and arm orders, and exact command.

Use the two retired seven-change test fixtures. Each has its own uv archive, immutable target seed, private Cargo registry and private released sysroot. Restore its previous Cargo and Wild slots by hard link when the phase exits. The original shared release and both immutable seeds remain read-only. Warm a single copied target on the new structural private-body edit `M00` or `Z00` and require a second invocation to be fresh. Copy that predecessor to persistent baseline and candidate target states, which are parked and restored at exactly the same absolute pathname for every command.

Before timing, trace the same next literal (`M01` or `Z01`) natively in both arms, each from its copy of the common predecessor. Require matching exact rustc argv multisets, matching Wild output rosters, six actual released rustc invocations and five actual Wild invocations. Require actual `uv` recompilation, the same complete 72 executable roster and no tests or network activity. Wild uses its default production fork and jobserver behavior. All timing commands run directly, without a syscall tracer, instruction counter, compiler/linker wrapper, or test execution. Each timed command must still recompile only uv and print that frozen executable roster. Readiness and after-cohort native audits validate the selected compiler and actual linkers.

Each cohort contains 24 prespecified same-length private literal edits and 12 baseline-first plus 12 candidate-first pairs. Both arms see the same new source bytes and modification time once per pair. The initial cohort uses shuffled `M10`–`M33`. The independent repeat uses shuffled `Z40`–`Z63` in a different archived root. Measure elapsed nanoseconds from just before process launch through Cargo exit with `time.perf_counter_ns`. Switch and verify executables, source contents and targets outside that clock. Save all raw samples in order, package and executable rosters, host data, prospective schedules and input hashes. Failures invalidate the endpoint's claim and remain in the evidence. Do not replace individual samples or change cohort size after seeing results.

Timed commands require a separate explicit quiet-window signal from the coordinator after other builds and counters have finished, the shared native measurement lock, and successful host preflight. The sampler uses CPUs 0–15 with `-j8`, as in the original elapsed-time studies. A monitor on CPU 31 records aggregate CPU 0–15 busy fraction, iowait and dirty/writeback memory. Before each cohort require two consecutive five-second windows with busy < 5%, iowait < 2%, dirty < 65,536 KiB and writeback < 8,192 KiB, plus absence of active external compilers, linkers and counters. Preparation and native workload verification can use CPUs 24–31 once those cores are released.

The estimate is the median paired proportional reduction, `1 - candidate / baseline`. Report arm medians in seconds, wins, ties, and a two-sided exact sign p-value excluding ties for each cohort. The symmetric distribution-free median interval uses ranks 7 and 18 of 24 (97.734% coverage for a continuous median). Claim a repeatable reduction only if both cohort medians are positive, both p-values are below .05, and the initial lower rank bound exceeds zero. Complete both cohorts regardless of initial direction.
