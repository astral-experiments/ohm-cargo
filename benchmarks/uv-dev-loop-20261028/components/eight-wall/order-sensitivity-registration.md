# Balanced-order sensitivity diagnostic

Registered while all original seven-change primary instruction cohorts were known and no independent instruction repeat had completed. Both eight-change elapsed-time fixtures had passed native admission. Neither had any timing sample. The original registrations, qualification rules, sample sizes, rosters, harnesses and release checks remain unchanged.

For each complete cohort also report an exact, two-sided conditional randomization p-value for the number of candidate wins. Condition on the observed first- and second-period values in every pair. Under the sharp null that assignment changes no value, redistribute the randomized baseline-first labels uniformly over all allocations having the registered number of baseline-first pairs. Count assignments whose absolute win-minus-loss score is at least as large as the observed score. A tied pair contributes zero and can receive either label. This conditioning allows arbitrary fixed differences between periods within individual pairs. It does not establish how a different source edit or host would behave.

The seven-change individual cohorts use four baseline-first assignments among eight pairs, giving 70 allocations. Their separate repeat uses a newly randomized order within the same balance. When both are complete, convolve their two exact score histograms, preserving all 70 × 70 independent, block-balanced allocations. Report this pooled diagnostic only alongside the two original cohort outcomes. The first stage is retrospective for this sensitivity analysis and the repeats were conditional on initial qualification.

The eight-change native study uses 12 baseline-first assignments per 24 pairs in each independent cohort, giving 2,704,156 allocations each. Use integer hypergeometric enumeration, which groups allocations by how many baseline-first labels land on positive, negative and tied first-minus-second period values. Report each cohort and the product-allocation diagnostic. This supplement neither changes the original sign and rank decision gates nor rescues failed outcomes. No observation is removed or replaced.

Run `python3 -B order_sensitivity.py roles /path/to/tree-count` or `python3 -B order_sensitivity.py wall /path/to/eight-wall`. The sidecar `order-sensitivity-results.{json,md}` in the supplied study directory records the independent diagnostic. Incomplete cohorts have no estimates. The wall diagnostic requires the complete audited pair files.
