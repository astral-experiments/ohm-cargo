This compares a bounded two-choice registry cache with the single-slot cache from Ohm Cargo #237. It measures final Callgrind instructions for the complete Cargo parent and its threads during a dirty uv `cargo check`. Compiler and linker children run normally and are not counted. It makes no whole-command elapsed or first-use performance claim.

Run `python3 -I -S -B reproduce.py` in this folder. It authenticates all 32 compressed profiles, independently sums self costs, checks final totals and retained stderr counters, and reproduces the two fixed eight-pair results. Each machine must independently have eight wins, exact two-sided sign p < .01 and a 99% lower reduction bound above 1%. The orders are mirrored, the bootstrap seeds are 20261025321 and 20261025322, and each interval uses 200,000 draws. Results are not pooled.

The two source-built Cargo binaries use matching stock Rust settings and the same embedded revision. The uv workload uses the unchanged published SDK12 Rust compiler and Wild. The reversible fixture changes five bytes in an equal-length ordinary comment. Source-only histories, actual compiler contexts, exact per-arm output hashes and restoration are checked independently on both machines. The second machine has a separately decoded seven-lifetime definition-number permutation across arms; every measured output must still equal its own arm's whole-file reference.

The fixed blocks exclude the single loader eligibility pilot and the replica preflights. Both complete restoration/raw gates and all 32 profile-integrity checks precede either estimate. There are no replaced observations, extensions or valid-result retries. Activity is recorded, not used to select instruction samples based on benefit. Path labels are sanitized without altering any other function, call, cost or counter bytes.

The 470-manifest corpus witness changed repeated writes from 49 (78,344 bytes) to zero, with 27 additional logical cache lookups. Both first-use passes wrote 470 entries; the two-choice cache retained 25 additional slots and 44,268 additional bytes. Actual ordinary warm caches matched those complete file contents on both hosts. These are cache-occupancy and corpus operation facts, not a first-use performance percentage.
