# Exact RC Cargo migration on retained released Ohm caches

The Cargo revision proposed for the replacement Ohm 1.99.0-17 was run twice on each of 14 retained workspaces with the original shipped 1.99.0-16 rustc. All seven native binary cases printed 29, including all five cases that previously returned a stale 17. All seven erroneous check cases produced the exact full E0308 diagnostics from their corresponding clean runs, including all five that previously exited successfully. There were 28 real Cargo commands and 14 separately invoked binaries.

The workspaces cover a spaced filename with or without a literal backslash-space neighbor, a normal hyphenated name, a spaced package root, and a symlink whose name contains a space. Some old ordinary records had already erased the unsafe path spelling. The first successful command retrained the old record. A plain-path control was fully fresh from the next command. When the shipped compiler cannot produce a reliable checksum, the new Cargo declines to reuse it. The final compiler path and Linux Ruff timing cohorts are qualified separately.
