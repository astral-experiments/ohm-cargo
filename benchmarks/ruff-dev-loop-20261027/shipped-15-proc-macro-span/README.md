# The packaged Ohm 1.99.0-15 Linux toolchain reproduces the warm/clean span difference

The project’s official Linux archive was streamed into a private tmpfs and verified against the SHA-256 published by GitHub. The included installer installed the compiler, Cargo and x86_64 standard library into a private prefix. Each tested binary matched its unmodified archive component byte-for-byte. The compiler reported 2169ab9678eb7c748acc1a9b89e7df21548dbd73 and Cargo reported 701d02b53c3530c833a26aac013f9a22dfd6386d. [Published release](https://github.com/astral-sh/ohm/releases/tag/ohm-1.99.0-15)

An otherwise empty derive parses and discards the token stream formed from the string `"0"`. An independent macro in a later included Rust file formats a token's Span Debug value into its native library. The program warms the original library, makes the same real `7 → 8` edit in both histories and clears only the unit’s incremental compilation directory in one. On the ordinary packaged toolchain, the warm native program printed `8:#0 bytes(373862..373872)` and the independent rebuild printed `8:#0 bytes(373864..373874)`. Both ordinary crossed-library callers failed with E0460. An otherwise equivalent macro using a programmatically constructed literal generated the same output and accepted both crossed callers. Cargo with Ohm defaults disabled also produced equal outputs and accepted both.

This check used no registry dependencies or procedural-macro trust overrides. The three groups all ran on the same physical H1 host and original distribution. It was a correctness test with no timed endpoint. It independently reproduces both the native byte-position and ordinary-reader behavior on already distributed bits. The qualified #232/#233 comparisons use their own compiler builds. [Two-crate #232 and #233 controls](https://github.com/astral-sh/ohm-cargo/tree/1b6d6e6fbb6ca86eb658b891f4980933a5a55d4d/benchmarks/ruff-dev-loop-20261027/proc-macro-parse-source-baseline)

Run `python3 -B verify.py` to check the packaged identities, raw metadata, argument lists, real compiler diagnostics and native program outputs. The included repro.py can be rerun on a private Linux rustup descriptor that links `ohm` to this exact distribution. It writes its fixture and artifacts into a new directory.
