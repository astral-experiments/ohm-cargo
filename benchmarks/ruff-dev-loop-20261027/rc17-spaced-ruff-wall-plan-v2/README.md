# Replacement source binding for the unchanged Ruff workspace timings

Before either measured workflow started, native rustc compiled two different libraries whose canonical paths had the same depfile spelling. One directory contained an invalid byte and one contained a literal Unicode replacement character. A source-order change altered which checksum survived. The former candidate was withheld from timing. The final compiler invalidates the colliding entry in both orders. Cargo distrusts ambiguous old records and keeps ordinary modification-time records usable.

The scored workflows still use the original Ruff checkout and the same two selections, 24 adjacent pairs per selection, fixed pair orders, four Cargo jobs, matched release profiles, product checks, exact test statistics, and minimum reporting threshold. This amendment binds the full source diffs and adds the new native correctness gate. Both release-source arms must finish their complete native qualifications before the first clock.
