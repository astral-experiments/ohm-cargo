`sh run.sh` builds one native derive and one native attribute with the selected Ohm toolchain and checks each against a fresh reader. The packaged `ordinary-cargo` fixture uses `cc` in a normal Cargo build script. The reader prints the value obtained by the derive. To reproduce, copy `ordinary-cargo` to a new directory, set `CARGO_TARGET_DIR` and `CARGO_BUILD_BUILD_DIR` to separate private paths, and set `CARGO_ENCODED_RUSTFLAGS=-Zcache-proc-macros=yes` for this explicit-option regression. Run `cargo +ohm build --offline` there, run the `plain_reader` binary, change the return value in `driver/native.c` from 17 to 29 and repeat. Compare to a run from completely empty target and build directories under the same source path.

On Linux, `python3 synchronized/exercise.py --root /absolute/new-workdir --sdk /absolute/ohm-toolchain` compiles two actual versions of the native library. It waits for the Rust process to execute the original implementation and open its executable mapping before replacing the library. Both fresh and preserved timestamps are tested. The workspace has no external dependencies. `rustup`, `strace`, a C compiler and permission to inspect the current user's `/proc` mappings are required. For the attribute variant, copy `synchronized`, apply `synchronized-attribute.patch` from inside the copy, then use its `exercise.py` with another empty work directory. The archive retains compiler arguments, typed output, actual native macro calls, and byte comparisons for the Rust metadata, dynamic symbol table and machine code.
