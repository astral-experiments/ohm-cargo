# Exact native linker inputs for the first Ruff workspace selection

This untimed qualification follows the stopped #260/#261 cohort on H5. The comparison uses the same released Ohm 1.99.0-17 compiler, Cargo images and stock Wild 0.11.0 on logical CPUs 0 through 15. The historical operation was `cargo +ohm test --no-run --workspace --locked --offline -j8` after selecting a previously excluded package. The source revision is Ruff `93526150df078af7dd8fc4226cdcc469539d2001`.

The old gate rejected two whole-file hashes on the fourth command’s separate unchanged repeat. The forensic packet binds the first 110 native product hashes, the failing repeat’s product and linker roster, and both earlier selected and repeat physical originals on each arm. The 36,947,872-byte formatter ELF moved from 0 to 8 in the `.rodata` section header’s `sh_entsize`. The 194,127,680-byte `ty_project` ELF moved from 8 to 0. The 32 GNU build-ID bytes also changed. Every other byte agrees in each respective comparison. The actual historical worker counts and transient physical inputs to those two individual links are unknown. The original timing cohort remains excluded.

1. Reconstruct the failing two link-only calls from the untouched failed state's exact `.rlink` and matching objects, using private output copies and the normal compiler→GCC→collect2 entry path. Each corresponding rejected raw hash must be reproduced by an actual ordinary stock link at one or more explicit widths. Keep all old qualified raw results.
2. Make three full independent byte- and metadata-verified copies of the admitted seed. Run the two genuine excluded-seed repeat commands on one copy. From each other copy run the selected workspace and its unchanged repeat on the corresponding Cargo. Collect the original six role/target rosters prospectively. Across them the requirement is 297 native jobs covering 50 distinct workspace targets. The first-selection baseline runs the same e2e harness twice and the treatment once. The remaining full native test compile is the ty_server package harness. Capture all 78 registry and 108 or 110 workspace products and actual test listings under the source-selected phases. Registry dependencies are checked again on both excluded commands.
3. At each real live linker entrypoint run the identical released Wild binary with its unmodified argv and inherited file descriptors. Keep the default output, inode and modification time. Under that same exact invocation, with Rust/GCC temporaries still live, run stock Wild first with dependency reporting and then without it at each explicit thread count from 1 through 16. The width order is fixed in the worker. Both probes use the identical original output pathname in a disposable build state. Preserve the genuine default file by a same-device rename and restore it before returning to collect2. Diagnostic writes and streams are private. The reconstructed failure commands do the same. At most three sets of explicit replays share the host at once. Every occurrence is assessed separately even when it repeats the same target or names the same bytes.
4. Record status and every actual stock child argv from `strace`. Check the complete ordered compiler-derived Wild vector, every regular literal file and every positive path reported by Wild, including system scripts and DSOs. Check the real temporary `symbols.o`, the empty or absent `raw-dylibs` search directory and the presence/content of GCC’s `-fresolution` operand. Hash positive names, actual resolved path, length and complete contents before and after all widths; recheck the name set at every reported width. Reject response files, overriding group/thread switches, malformed dependency files or a changed operand. These checks qualify this completed fixture: its past traces do not authenticate bytes discarded by an earlier compiler.
5. Require equality of each reporting/plain pair by complete raw file SHA-256, then independently reread every retained raw ELF. Compare all three unmodified byte ranges and both exact ELF field offsets with all four physical selected/repeat references. Require each fresh default output to reappear in a width pair on its own literal argv. Require every retired qualified digest, both omitted past digests, all matching unaffected outputs, the exact package roster, diagnostics, executables and genuine native process counts. The admission catalog enumerates only exact observed whole-file SHA-256 values.
6. Exhaustion is bounded at 299 true occurrences, 9,568 explicit Wild probes and 299 default links. Any failed cross-check leaves the evidence insufficient. No replacement state or relaxed criterion is permitted by this protocol. A disposable worker failure records the last full trace; the pristine seed, failed slot and qualification outputs remain read-only. Public results omit argv/path contents of private registry material while exposing their exact hashes and typed public target names.

## Resource limits and interpretation

The physical H5 scratch device initially had 219,950,632,960 free bytes. Each new seed copy must fit with a 6 GiB working allowance and 38 GiB physical reserve. Every native width and every Cargo phase rechecks free space. Probes have a 180-second execution watchdog, reconstructed commands have a 20-minute watchdog and the complete worker has a four-hour operational limit. Watchdogs are failure limits and produce no performance measurements. All writes go to `whole-wild-width-v1`. The earlier seed, successful/failed comparisons and stopwatch records are excluded from the operation. A future timing design requires an independently reviewed, immutable exact raw catalog.

Stock Wild `e856d81f6683cad80b9fe0ebf1a0c3c403c6fe11` uses its explicit width if supplied. With the inherited Cargo jobserver it builds one worker plus the tokens it can acquire from the `-j8` command. Without a usable jobserver it uses available parallelism (16 here) capped at 32. Its object grouping reads that effective width. Per-group section attributes are applied to output sections and assign the aggregate entry size. The source snapshot records the upstream file hashes and locations. The effective width of a historical default link is not inferred from its ELF. Each proposed finite raw alternative must be physically reproduced.
