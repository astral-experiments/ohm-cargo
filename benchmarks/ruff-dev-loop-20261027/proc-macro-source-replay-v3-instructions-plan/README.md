The unit of measurement is one resolved native compiler process for Ruff's parser library, including actual code generation and the registry derive. Its arguments come from ordinary workspace Cargo on Ruff commit `93526150df` and the complete historical edit `3ea20f6161`. Each invocation has independent writable outputs. The 16 real direct externs, parser source, SDK, registry plugin and logical paths match. The retained endpoint starts from the original source's incremental state for its own compiler arm. The empty endpoint starts with an empty parser incremental directory. Both produce a native Rust archive. Cargo scheduling and rustup dispatch happen outside the counted application.

Three same-image trials per endpoint agreed within 0.059% of their empty median and 0.027% of their retained median. Each had 83 matched thread start/exit records, one PID and one SIGUSR1. The three-thread assembly calibration gave per-thread counts of 3,000,065, 3,000,028 and 3,000,028. An earlier manual invocation omitted the toy's required arguments, immediately hit SIGSEGV and exited 139. Its signal and complete 15-instruction trace remain in the packet. The toy's valid single-thread control counted 3,000,052.

The counter counts decoded application instructions on basic-block entry using a per-thread register-backed count. Each rustc run requires complete process and thread exits, the same PID mapping the selected frontend, compiler driver, proc macro, runtime and counter, raw stdout and exact compiler stderr against an ordinary same-arm/same-history reference. The pinned x86_64 release collector emits a fixed prefix of startup warnings about the absent x86/debug runtimes. Its prefix is compared separately. Each archive must have identical ordered object payloads, raw embedded and separate Rust metadata, GNU symbol-to-member ordinals, and member-directory contents after replacing only rustc's per-invocation seven-character CGU suffix. Raw archive SHA-256 values are retained. The 10th of the 12 ascending paired ratios gives a one-sided upper median bound with at least 98.07% coverage under the paired sign model. Both such bounds must be strictly below +3%, giving at least 96.14% simultaneous coverage by the union bound. The wall studies retain their original interpretation. An incomplete ledger, timeout, mismatched native output or changed input closes the whole comparison and preserves every partial result. No replacement process or additional pair is allowed.
