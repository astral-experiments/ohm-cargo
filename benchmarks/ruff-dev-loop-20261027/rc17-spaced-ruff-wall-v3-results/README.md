# Unchanged Ruff test builds with matched Ohm -17 sources

Each command used the same pinned Ruff checkout at `93526150df078af7dd8fc4226cdcc469539d2001`, four Cargo jobs, a warm independently trained target per subject, and locked, offline dependencies. The timed command was `cargo +ohm test --no-run`. Two registered workflows selected either the whole workspace or the `ty_project` package. The comparison uses the canceled and corrected release sources built with a common Rust frontend, standard library, Wild linker, version stamp and training profiles. The Rust driver and Cargo changed together. These are source-built subjects. The corrected package binary is a separate qualification.

| Selection and directory containing a space | Canceled median | Corrected median | Paired reduction (95% interval) | Faster pairs |
| --- | ---: | ---: | ---: | ---: |
| `--workspace`, SDK directory | 9.400 s | 1.059 s | 88.72% (87.57–89.82%) | 24/24 |
| `-p ty_project`, target directory | 2.252 s | 0.421 s | 79.15% (76.51–81.23%) | 24/24 |

Each workflow randomly assigned 12 pairs in either order. Both two-sided tests had 2 equally or more extreme assignments among 2,704,156. Each Holm-adjusted p-value was 0.0000014792. The intervals are fixed-seed paired bootstrap intervals for the geometric mean ratio. Neither command ran test bodies. Process tracing was confined to separate qualification runs.

In the native workspace qualification, one full rustc, 50 link-only rustcs and 50 actual Wild invocations became zero after training. All 619 corrected units stayed fresh. In the package qualification, two full rustcs, one link-only rustc and one actual Wild invocation became zero, and all 303 units stayed fresh. The offline verifier rechecks 96 command clocks, all executable rosters and harness listings, every native product hash against its own source arm, and the registered cross-subject file pairs. In the workspace there were 102 executable selections and 110 native files. Across arms 106 files matched byte-for-byte, and four had exactly the pre-registered byte pairs. Those four embedded their own Cargo output directory in jemalloc debug information. The package had one selected executable and four native files, all matching across arms. In the corrected arm every file matched its reference byte-for-byte in all 48 commands.

The original plan stopped before timing on the workspace file comparison. An untimed investigation attributed every raw difference to three debug sections and the GNU build ID and compared all decoded DWARF attributes, macro entries and strings. The replacement plan fixed the four exact byte pairs before measuring. The archives include the protocol, both reference streams, clocks, per-slot validation, the original hash and portable hash of every exported file, and the complete trial ledger. Run `python3 -B verify.py` in this directory to recompute both outcomes.
