# Unicode generator change in an ordinary Ruff CLI build

Reversing the complete `ruff_unicode_names2_generator/src/formatting.rs` projection of Ruff commit `bfedc614b7670b8766576b64afd426c292f8c2ce` changes two generated files. On Ohm 1.99.0-16 three full compilers ran in each source direction. Neither the Python parser nor the linter needed a full compile. Ruff invoked link-only rustc and Wild, producing a byte-identical 150,901,720-byte executable through both changes.

The experiment used pinned Ruff `93526150df078af7dd8fc4226cdcc469539d2001`, ordinary unspaced paths and the default released toolchain. The projected generator file is one of 12 files in the source commit. Its complete reversal adds the literal eight bytes `'static ` after the reference ampersand in two Rust text templates. The package manifest, generator implementation, Unicode database, name aliases and consumer stayed at the frozen pin. The pre-exposure design and SHA-256 for the official Cargo, rustc frontend, rustc driver and Wild are in `unicode-plan.json`.

## Physical native commands

The primary sequence ran six `cargo +ohm build --locked --offline --message-format=json -p ruff --bin ruff` commands in one isolated, independently provisioned and already warm native store. Raw typed Cargo artifact records were joined to successful execs and their actual exits. The Ruff registry and worktree trust configuration was the Ohm default.

The three full compilers produced the generator library, the build-script binary and the Unicode runtime library. One Wild invocation linked the new build script and the other linked Ruff. The generator’s native archive kept 170 of 173 ordered object payloads. All 173 member names changed. The generator's symbol index had 1,472 entries in each source condition, and the mapping from symbol to member ordinal changed. One native object had changes in four machine-code sections. The linked build script differed in both its complete `.text` and `.rodata` and reverted to the original whole-file SHA after restoring the source.

## Native link boundary

All 13 runtime-library object payloads were identical in archive order, as were all 37 exported symbol-to-archive-member ordinal pairs. All 13 native object member names changed, the raw archive symbol table changed, and the whole archive passed to Wild changed. Of 307 explicit file arguments to the Ruff native link, one `symbols.o` was no longer available for after-command hashing. The 50 explicit inputs to the build-script link had 13 such missing native temporaries. No exhaustive record of implicit linker scripts or unsuccessful lookups was captured here. A prior full native counterexample selected a section by its input archive member name and changed a program’s exit status from 83 to 41 when that name moved. The result supports neither omitting the native link nor preserving stale generated Rust files. [Native archive member-name control](https://github.com/astral-sh/ohm-cargo/tree/b6929e5953af1ffe15ce3f1716dd2f181c95faff/benchmarks/ruff-dev-loop-20261027/native-archive-name-observation)

The initial runner searched for script stdout beside `out/`. This Cargo layout stores the physical receipt in the sibling `run/stdout`. The original six rows retain that capture gap. A separate unscored replay ran the reverted and restored ordinary CLI builds and reproduced their complete physical process rosters, generated bytes and build-script ELF hashes. It captured identical script stdout, stderr, output-directory records, all 22 retained Ruff codegen objects, the complete Ruff link plan and all final ELF section hashes. The original and restored native binary archives were separately re-opened and verified. All observations are structural. No command time or speedup estimate was inferred.

## Recheck

Run `python3 -B verify.py` and `sha256sum -c SHA256SUMS`. The 203 recorded files bind original SHA-256, sizes and portable contents. Eight text records replace one private registry hostname with `compiler-registry.invalid`. Six full rlibs contain that private address in native debugging paths. Their ordered archive membership, per-member and ELF section digests and symbol-index membership are supplied in `native-members.json.gz`. The actual standalone Rust metadata and extracted ELF metadata members are retained by digest in the content archives. The private complete native archives can be verified with `python3 -B archive_reader.py /path/to/rlib ...`.
