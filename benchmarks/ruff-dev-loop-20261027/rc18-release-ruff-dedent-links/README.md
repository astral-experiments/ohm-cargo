# A three-file Ruff edit across the fifty warm Linux test links

Reversing Ruff’s RET505 dedent fix changed executable machine code in five of the fifty targets that relink on an unchanged workspace build. Nineteen additional ELF files changed while keeping identical allocated section payloads apart from the build ID. Twenty-six files were byte-identical. The genuine edit ran 111 full rustc invocations and 75 packaged Wild links in total. The fifty below are the fixed subset identified by the preceding unchanged command. [Ruff source change](https://github.com/astral-sh/ruff/commit/83a3afc3156d73ae4296f3fa74ede28e4c72bfcd)

The five code changes were the Ruff integration test, Ruff library test harness, linter library test harness, Markdown test harness and Ruff server e2e test. The real `ruff check --select RET505 --unsafe-fixes --fix-only` command produced a Python function returning `2` on the original false branch and `None` after the reversal. The edit and the independently empty-target and empty-build-directory run produced the same fixed Python program. Restoring the three files restored its original behavior.

Forty-six of the fifty complete warm edited executables matched the independent clean ones byte-for-byte. The remaining four differed in the GNU build ID or section headers with identical allocated program payloads. The full edited `ty_server:e2e` ELF matched its clean build exactly. On restoration, 48 of the 50 full ELFs matched this run’s initial state. The two differences were likewise confined to the build ID or headers. The installed stock linker can produce different complete ELF bytes at different worker widths.

The six ordinary, unscored commands used the public Linux Ohm 1.99.0-18 installer, Ruff `93526150df078af7dd8fc4226cdcc469539d2001` and `cargo +ohm test --workspace --no-run --locked --offline -j8 --message-format=json`. The two unchanged repetition phases each had one full ron compiler, 50 true link-only rustc invocations and 50 real native linkers. All six commands reported 619 Cargo artifacts. The original installer, executable identities and independent native-library controls are recorded in the released-link census. [Released-link census](https://github.com/astral-sh/ohm-cargo/tree/f4accac238a41900a6e18239dece4be2c5463fa4/benchmarks/ruff-dev-loop-20261027/rc18-release-ruff-link-census)
