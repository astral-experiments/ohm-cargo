# Recompiling an observer on a completely unchanged Ruff workspace

A fresh offline Ruff checkout at `93526150df078af7dd8fc4226cdcc469539d2001` ran one cold and nine unchanged `cargo +ohm test --no-run --workspace --locked --offline -j8` commands on Linux. Cargo source `9a0170863f70d9a88a8b1d1f4c4e1fded4736a9c`, executable `0aa04df8…`, recompiled the foreign span reader on every invocation. The release-profile, source-matched raw-path compiler was `52d5c046…`. All ten commands used ordinary default trust, the same target and registry, and JSON output. They built test executables without running the test suite. This dataset contains no timed observations.

Every unchanged command recompiled only `ron 0.12.0` in full. Its complete native archive, including the symbol index, 10 codegen objects, `lib.rmeta` and `lib.rmeta-link`, was identical on all ten builds. The full standalone 1,443,299-byte `.rmeta` took four distinct values. Two of the nine adjacent transitions had identical bytes for both the archive and metadata. The original four root headers had equal public hash, private hash and stable crate ID, and the compiler's entire `-Zls=all` listing was identical. These observations do not establish exchangeability of different metadata bytes. The supplement records original file inode, ctime, mtime, size and SHA-256. Cargo restored the standalone metadata mtime even across byte changes. The archive mtime advanced on every captured recompile.

Nine successful commands also have post-command Ruff and ty version/diagnostic checks and actual listings for four stdlib and 200 ty_server tests. The first supplemental command succeeded and its 619 artifact messages, all 110 ELF hashes and complete native traces were preserved. Its reporter failed on a missing copied input manifest before running the post-command listings. The remaining five commands then completed on the same unaltered history. Every command reported 102 executable targets, of which 84 had the test profile; the physical output roster contained 110 ELF files.

## Actual native links

Across the first three repeats, the 50 real linker argument lists named the complete ron archive once in 35 commands. The remaining 15 omitted it. No Wild command named a standalone `.rmeta`. All 50 passed five external startup objects, the same seven dynamically searched `-l` names (gcc_s, util, rt, pthread, m, dl and c), the GNU dynamic interpreter, GCC's LTO plugin, wrapper and temporary resolution option. All searched the compiler's temporary raw-dylibs directory, two SDK directories and eight GCC/system directory spellings. Sixteen searched psm, 21 searched psm and zstd-sys, and 13 also searched jemalloc. None used an explicit script or response file. The exact options and target identities, including all 15 with no direct ron operand, are in `operands.json.gz`. Arguments alone do not identify implicit linker-script inputs, failed lookups or whether a plugin claimed a file.

Two ELF outputs varied over the original four commands; four more varied in the six later commands. For each, the exact recorded link-only compiler created the real transient inputs. The released Wild executable `0d633580…` ran six times with the same files while those temporaries still existed. Width one and widths two, four, eight and sixteen reproduced both historic unmodified full-file SHA-256s; the default-width run matched the wider group. The varying bytes fit exactly one eight-byte `.rodata.sh_entsize` field and one 32-byte GNU build-ID descriptor. Every other byte matched. The entry size switched between zero and eight in five executables, and zero and one in the formatter fixtures executable. These are genuine distinct ELF bytes. The diagnostic used explicit worker widths; it did not recover the original jobserver counts. No product reuses a saved executable in this study.

`original.json.gz` includes exact source receipts, extracted process and archive ledgers, all original ELF identities, and a separate five-compiler replay. That replay used a different frozen release-profile driver, retained all six extern artifacts, and varied only the captured ordinary versus explicit observer flag suffix in the compiler argv. The matched explicit repetitions produced identical archive and metadata bytes. Ordinary repetitions preserved the archive but also reproduced metadata variability. The raw phase captures and ELF files remain on the isolated native host. Checksums authenticate the included files.
