# An edited Ruff TypedDict test reuses its compiled harness

The complete reverse of Ruff be042539847afee4223e92ce271b080d70c91ea8 changes the runtime test input for closed TypedDict get. It added 93 lines and removed 29 when originally committed. We selected it from Ruff history before observing the native jobs. The package and harness were tested on a clean, pinned Ruff checkout and the unmodified Linux Ohm 1.99.0-16 release. The measured scope is one package and one named harness. [Complete historical change](https://github.com/astral-sh/ruff/commit/be042539847afee4223e92ce271b080d70c91ea8). [Harness reads the Markdown at runtime](https://github.com/astral-sh/ruff/blob/93526150df078af7dd8fc4226cdcc469539d2001/crates/ty_python_semantic/tests/mdtest.rs).

Ordinary cargo +ohm build -p ty_python_semantic produced 241/241 fresh and cargo +ohm test --no-run -p ty_python_semantic --test mdtest produced 301/301 fresh on the settled original, full historical edit and source restoration. All six commands returned zero and launched zero full rustc, link-only rustc, build scripts or Wild. The new empty build target initially ran 243 full compilers and 43 Wild. Adding the test command to that prime ran another 104 full compilers and ten Wild. All 241,782,768 bytes of the selected test profile Rust library, 23,648,853 metadata bytes and 175,437,920 harness bytes retain their original SHA-256 digests.

The standalone filter mdtest::typed_dict.md subsequently passed on all three source states, using that same compiled executable. Reader syscalls for the exact opened file returned 286,133 bytes originally, 284,757 on the edit, and 286,133 after restoration. An extra 31,161 bytes read from other files whose *contents* mention its name are excluded. The recorded dep-info of both Rust library profiles and the harness contains each Rust root, and omits the Markdown input. This case already avoids all compiler and linker work. There is no new performance claim.

The first remote setup request ended before a Cargo command when its shallow repository lacked the parent of be042539. The full patch from the complete local repository was sent directly, its registered SHA-256 was verified, and the entire experiment ran in newly created empty private directories. The three source states use read-only per-file overlays on the same physical Ruff checkout. Every filesystem stayed above the 25 GiB reserved floor. Subprocess logs, including the full per-PID exec and filesystem traces, remain on the collection host. The portable file contains their individual digests and the independently decoded successful open and read receipts.
