# Cached mixed-library metadata can reference a removed source file

The experiment uses the private mixed-library Cargo `cce63aae8421814ef7231bbd6c3a44f074c8fed6c3c9c34d4a32323f597a2773` and private compiler driver `c61eaa6cc336b48958e7712104e09182a287f2a33b4aa181b16a535c08e6a824`. A leaf crate exports a declarative macro from `macros.rs`. A mixed cdylib/rlib calls that macro to define public generic functions. A separate external Rust binary imports the mixed library and instantiates the functions. Sources and native code generation use identical canonical paths throughout.

Nine private source modules immediately preceding `mod macros;` change from `#[cfg(any())]` to `#[cfg(all())]` and back. The leaf Rust public hash stays `f5d2df9c07489465f549367dac7216be` and its native retained-symbol signature stays `2134935d61d9b40db91c5ed031fb3303`. The mixed library actually takes `-Zlink-only` after each edit. The first edit retains stale standalone and archived mixed metadata but yields the same full shared object and codegen object bytes as an independently forced full compile. Its fresh Rust caller prints the same panic locations, while its ELF bytes differ.

After the first edit, a full reference compile seals the expanded source layout as the mixed-library cache. Reverting the nine private files then replays the cached library. Compiling the external caller exits 101 with a rustc ICE, `missing source file` at `rustc_metadata/src/rmeta/decoder.rs:1905`. The backtrace runs through `get_module_children` and `decode_span`. Removing only the cached shared object forces a full mixed compile at the same paths. The identical external caller now builds successfully and prints `bundle/src/lib.rs:1:1` and `leaf/src/lib.rs:12:51`. Stale and repaired shared object bytes agree exactly. The separate and archived mixed metadata bytes differ.

The direct producer encodes a dense two-byte source-table offset per on-disk file index. With the siblings disabled, `macros.rs` occupies index 0 and `lib.rs` index 1. With them enabled, indices 0–8 contain the sibling files, `macros.rs` occupies index 9, and `lib.rs` index 10. The short table reappears byte-for-byte on restoration. The retained metadata contains a foreign span pointing to an index that no longer exists. `decode-tables.py` verifies every little-endian serialized pointer against the corresponding source filename. `producer-source-tables.json`, the three actual raw producer metadata files, the stale/repaired mixed metadata pair, original failing process log and actual compiler argv preserve the mechanism.

Run `python3 foreign-index.py <new-private-directory> <candidate-cargo> <candidate-driver>` using the canonical sysroot described in `common-guards.py`. On this candidate it stops at the expected external ICE. Run `python3 recover.py <same-directory> <candidate-cargo> <candidate-driver>` to force a full compile of only the mixed library and verify caller recovery. `producer-tables.py` records the two producer metadata files for a direct source-index check. These are machine-specific evidence programs.

Four separate fixtures exercise the original candidate's conservatism. Moving an actual upstream `#[inline(never)]` generic instantiation from u128 to u64 changes the Rust hash while keeping the native signature identical, and forces a full mixed compile. Loading and then unloading a previously unused transitive crate without changing any manifest also changes the Rust hash. Making a retained static thread-local leaves the Rust hash identical but removes the native signature, causing full compilation both ways. Changing a constructor pointer in a retained `.init_array` slot preserves both hashes and safely replays the mixed library, changing its observed initialized value from 101 to 202. Renaming the retained slot changes the native signature and forces full compilation. All thirteen independent stages matched a forced full shared object, mixed metadata, dynamic export list, codegen objects and runtime result.
