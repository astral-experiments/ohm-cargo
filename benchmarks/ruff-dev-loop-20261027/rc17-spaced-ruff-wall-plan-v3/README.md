# Ordinary Ruff test-build timings on the corrected release sources

The original trial stopped before either endpoint produced a timing. Cargo includes the compiler’s identity in artifact directories. The four package files matched byte for byte. Of the 110 workspace files, 106 were byte-identical. The other four contain a different compiler directory in jemalloc’s debug info. An independent full-file and DWARF comparison checked those four before this registration. [Zero-clock rejection and debug data](https://github.com/astral-sh/ohm-cargo/tree/4dd4b47a36089dae1fa0a5f8900ce8fcb8d99179/benchmarks/ruff-dev-loop-20261027/rc17-spaced-ruff-debug-qualification)

This trial binds the four exact file digest pairs. It compares every other workspace product byte for byte, and compares complete Cargo artifact fields after matching the two literal compiler directory names in typed outputs. After every timed command, all product identities are still checked against that arm’s own reference. The corrected arm must retain every native byte. The matched parent can vary only in the two previously registered Wild fields.

Both endpoints retain all 24 original adjacent assignments, the same Ruff checkout and source edits, the same Cargo commands and four jobs, diagnostics and harness listings, the original monotonic clock, exact test and two-endpoint decision rule. A change in any newly bound artifact or a failure of an original within-arm check withholds the measurement.
