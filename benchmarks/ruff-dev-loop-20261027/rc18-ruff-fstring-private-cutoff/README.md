# Stock Ohm and a private Ruff AST body change

Ruff changed a private, non-generic helper that classifies f-strings. Its linked consumer actually defines an out-of-line `is_non_empty_f_string` function. We reversed the complete historical three-file patch at the original commit and restored it. A second history reversed only the three-byte `any`/`all` method token. The original patch no longer applies cleanly to the newer campaign pin. Both histories used the July Ruff checkout and its unchanged lockfile, an authenticated Linux 1.99.0-18 installer, default Cargo behavior, eight jobs and no wrappers. The full patch rebuilt 30 pure Rust libraries including the AST producer, two mixed `cdylib`/`rlib` units and six binaries. All 32 associated complete `.rlib` and standalone `.rmeta` products changed. All 32 public hashes changed. The AST changed two of its 209 native objects. Each of the other 31 libraries preserved the multiset of complete native object payloads, but changed actual archive member names and metadata. The downstream parser, for example, kept 78 of 78 object payloads. A normal independent rustc caller succeeded with the two matching parser/AST pairs. It returned E0460 when the previous parser was used with the new AST in either direction. Rust's ordinary metadata dependency check and the externally observable archive member names both constrain any reuse. [Earlier archive-name linker control](https://github.com/astral-sh/ohm-cargo/tree/b6929e5953af1ffe15ce3f1716dd2f181c95faff/benchmarks/ruff-dev-loop-20261027/native-archive-name-observation)

The real CLI and the separate Rust caller consumed four f-strings. Ruff reported SIM222 only on line 1 of the corrected source and on lines 2, 3 and 4 of the fully reversed source. The caller returned `Truthy, Unknown, Unknown, Unknown` versus `Unknown, Truthy, Truthy, Truthy`. The complete diagnostic JSON and all four Rust verdicts matched the independently empty edited build, and restoring the source restored the original verdicts. Warm and empty program ELF files can differ on this host. Their individual raw digests are recorded. In the symbolized external executable the adjacent, unedited `is_empty_f_string` moved from `helpers.rs:1629` to `helpers.rs:1626`, including in the independent empty reverse.

The token-only reverse changes two bytes in a three-byte method name without changing any byte offsets, line count or file length. Its AST private hash changes, but its public hash stays `29babfc5e059887ab2d99b404d200798`. The previous complete parser and linter libraries stayed fresh on the forward measurement. Ruff flagged only line 2, and the separate Rust caller returned `Unknown, Truthy, Unknown, Unknown`, identically on the empty build. The adjacent symbol stayed on line 1629. Restoration also rebuilt the Ruff and ty libraries and binaries. The compared warm and empty Ruff and caller ELFs were not byte-identical, despite matching observable results. The two full baseline jobs were `ty_python_semantic`, whose actual `.d` contains the foreign-span observation prerequisite, and mixed `ty_wasm`. No proc-macro binary was recompiled in the two warming edit steps. `all-rosters.json.gz` commits every member's raw header, payload SHA-256, name, length, ELF magic and order for 236 distinct physical workspace archive bodies. It also records the released compiler's decoded private/public root and exact standalone metadata digest for 163 metadata files. Each of the 13 Cargo commands has its own raw argument/process, artifact, stderr, exit and output commitments. The larger raw archives, raw trace files and native executables were retained on the measurement host. The JSON packet alone cannot recreate the raw archive bodies from their digests. No wall-time distribution was collected.

The first external-caller fixture used symlinks to content-addressed blobs and omitted Cargo’s hashed `.rlib` sibling. Both current inputs were unavailable to the native linker in that layout. The corrected control created real, hash-verified `.rlib`/`.rmeta` siblings using the release's dependency filenames and succeeded on both matching inputs. An initial reporting pass also collided on two phases’ registry build-script basenames. The final reporter joins workspace library role and complete logical output path. These two reporting/setup failures did not rerun the original Rust/Cargo samples.
