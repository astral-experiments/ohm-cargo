# A native link can reuse an object with a stale assembly operand

On x86-64 Linux, the integration test reads a symbol defined by stable Rust `global_asm!` and LLVM’s `.incbin`. The real LLVM backend opens the package’s one-byte `payload.bin` when it assembles the test. Cargo and rustc’s produced depfile names the integration test Rust source and omits that backend input. Each case starts in its own target, build directory and registry home. There are 74 ordinary Cargo commands across eight cases. Compiler options, file open results, actual linkers, the executing test and independent empty results are retained for each phase.

| Actual Cargo / incremental setting | Real Rust edit and new payload | Subsequent source restoration, payload absent |
| --- | --- | --- |
| Current native-relink candidate, incremental off, previously unused package library | Cached-codegen rustc and stock Wild. Test returns 17 | Cargo succeeds with the last forced value 29 |
| Previous Cargo, incremental off, same unused library | No reader compiler or linker. Test returns 17 | Cargo succeeds with the last forced value 29 |
| Either Ohm Cargo, incremental off, actually used library private-body edit | Cached-codegen rustc and stock Wild. Rust result correctly changes 6 to 10, assembly remains 17 | Cargo succeeds with the last forced value 29 |
| Ohm defaults disabled, incremental off, each Rust edit | Full compiler opens the input and test returns 29 | Full compiler reports the missing file and Cargo exits 101 |
| Current candidate, incremental on, unused package library | Cached-codegen rustc and stock Wild. Test returns 17 | Cargo succeeds with 29 |
| Ohm defaults disabled, incremental on, unused package library | A full rustc process reuses previous incremental codegen. Test returns 17 | A full rustc process reuses 29 and Cargo succeeds |

An independent empty compilation always returned 29 for the changed operand. Every independently empty compilation with the operand absent returned 101 after rustc received ENOENT. With incremental compilation disabled, forcing a true compile in the same target reopened the operand and matched the empty result. With incremental compilation enabled, a forced compiler process initially reused 17. Moving only the integration test’s own incremental cache aside caused a true compile to read 29. The same forced-empty-cache check rejected the missing operand. Every recovery restored the original test values.

The older Cargo binary comes from `34dad66f`. The broader candidate comes from `fd872c05` and carries the parent’s development version stamp. The two toolchains used the identical physical Rust compiler, standard library and official Wild. Disabling Ohm defaults selected the system GNU linker. The comparison locates the change before the native linker because kernel traces record whether the code-generating rustc opened the operand. Same-state forced and empty Cargo slots under the candidate alone also reproduce 29 and the missing-file error using the same stock Wild setup. Some real empty-target invocations launched two reader compilers. Both are preserved, along with every observed final linker.

For the previously unused public dependency, Cargo’s old whole-executable shortcut already yielded the stale result. The newer dirty-integration branch runs a genuine native link, which still receives bytes from the earlier assembler operation. The private function case exercises the older dependency-only codegen reuse independently of the new unused-public branch. The ordinary incremental result is a separate limitation of rustc for this untracked assembler input. [Cargo native link decision](https://github.com/astral-sh/ohm-cargo/blob/fd872c053bb1e9dcde722cf90a05a7cb8335dd32/src/compiler/mod.rs#L1468-L1487)

The compiler hands a generated assembly string to LLVM and computes Rust dep-info from source-map and explicitly tracked files. The same compiler already excludes general assembly from ThinLTO object-cache publication. Its existing regression changes the bytes of an actual `.incbin` operand and runs both resulting programs. That gate covers LLVM module-level assembly and inline assembly calls. The source bindings include exact Git blobs and hashes. [LLVM global assembly](https://github.com/astral-sh/ohm-rust/blob/5e3de497d41f4d4fa98fce3082ea43076779de5d/compiler/rustc_codegen_llvm/src/asm.rs#L505-L510) [Rust dep-info](https://github.com/astral-sh/ohm-rust/blob/5e3de497d41f4d4fa98fce3082ea43076779de5d/compiler/rustc_interface/src/passes.rs#L623-L650) [ThinLTO cache exclusion](https://github.com/astral-sh/ohm-rust/blob/5e3de497d41f4d4fa98fce3082ea43076779de5d/compiler/rustc_codegen_llvm/src/back/lto.rs#L812-L820) [Existing Rust regression](https://github.com/astral-sh/ohm-rust/blob/5e3de497d41f4d4fa98fce3082ea43076779de5d/tests/run-make/ohm-thinlto-cache/rmake.rs#L87-L109)

Run `python3 -IB verify.py` to check the sealed observations. Run `python3 -IB reproduce.py SDK ABSENT_DIRECTORY --incremental 0 --relationship unused-public` for the discriminating public case. Append `--defaults-off` in a new directory for the normal full-compile control. Use `used-private` for the used-dependency case. The acquisition requires strace permission and its registered private disk reserve. It measures behavior and native process counts.
