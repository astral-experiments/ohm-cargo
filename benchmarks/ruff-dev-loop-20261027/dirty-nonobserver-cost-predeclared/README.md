# Cost of rustc capability discovery on a real Ruff edit

This prospective study measures two dirty one-package commands on Ruff at 93526150df. The complete reverse of 61a49c89eb removes TextRange::to_std_range. No package or source change is added to Ruff. The arms hold the new release-profile compiler constant and change only Cargo.

In 40 unscored calls from eight independent stores, the candidate started one extra rustc capability query on every dirty cargo check and cargo build. The old Cargo started zero. Both fully compiled the one selected Rust unit, emitted four ordinary source checksums, recorded zero foreign-span observations, and launched zero compilers on the subsequent unchanged command. The ordinary caller failed with E0599 on the edited source, then compiled again on restoration and printed 2-6. Checks of both codegen objects and the Rust-interface bytes matched. Independently rebuilt rlibs naturally carry fresh temporary CGU member names. The raw names, whole hashes, and member bytes are retained in the control packet. The auxiliary link-metadata bytes match after substituting only these two actual names. No wall results from these controls enter the study.

Schedule.json fixes 24 balanced paired trials for each command (96 timed invocations), the two-arm release inputs, two-sided stratified exact tests, multiplicity adjustment, and the independent 3% and 5 ms small-cost bounds. The ordinary dirty command is timed inside the fixed four-core namespace. Input edit, native proof and real Rust caller run outside it. Both positive and negative results will be reported separately from the 619-unit first-observer studies.
