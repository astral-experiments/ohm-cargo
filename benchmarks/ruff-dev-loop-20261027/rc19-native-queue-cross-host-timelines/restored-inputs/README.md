# Persistent native argument differences after restoring the Ruff edit

Across the last two diagnostic workspace commands, all 51 rustc argument digests agreed. Of 150 native argument vectors, 129 agreed after the registered temporary-role comparisons. The remaining 21 came from seven targets. Every difference occupies a persistent object-file argument. The directory, target name and codegen-unit stem were identical. Each target had one seven-character suffix per arm immediately before `.rcgu.o`. The same 456 substitutions appeared at the corresponding object positions in GCC, collect2 and Wild, giving 1,368 differing fields. All recorded lengths, ordering outside the substitutions, and compiler-created temporary roles agreed.

Each original and replacement path was reopened from its respective held target. All 456 object pairs had identical SHA-256 and size, amounting to 33,492,416 bytes on each side. The object timestamps preceded the observed native execs. These hashes were obtained after the final trace. The tracer directly captured the temporary symbol object, resolution file and raw-dylibs directory at Wild entry. The complete absolute paths appear in each arm’s own saved Rust link-state binary and in the matching Cargo cache manifest for all 456 objects. Six of the seven targets also had identical complete final binaries. The remaining target was the `ty_server` e2e test.

The released compiler draws one random 32-bit value for the output names of an incremental invocation, formats it at a fixed width and appends it between the codegen-unit name and the `.rcgu.o` extension. Explicit saved link state retains these distinct paths so that another compilation can coexist with it. Cargo puts its saved objects in each target’s `.rlink-objects` directory. Both measured Cargo commits share the same source blob for this operation.
