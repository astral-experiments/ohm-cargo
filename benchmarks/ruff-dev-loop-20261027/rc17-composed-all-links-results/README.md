# Stock Wild outputs across all available linker widths on H5

Six genuine Ruff workspace commands linked 50 distinct workspace executables across 297 occurrences. Each acquired native invocation ran first with its original arguments and inherited scheduling, then with each explicit width from 1 through 16, with and without Wild’s dependency report. A separate replay reconstructed the two rejected physical files. The independent reader verified 9,867 successful stock processes from their actual argv, exit records and exact output bytes. The two reconstructions remain separate from the six regular command phases. [Original native protocol](https://github.com/astral-sh/ohm-cargo/tree/5b9490236f0557fb748a7b7e527e45452002904b/benchmarks/ruff-dev-loop-20261027/rc17-composed-all-links-protocol)

All 16 pairs agreed byte-for-byte between the ordinary and dependency-reporting linker paths for each fresh occurrence. The actual default output was present among that occurrence’s complete SHA-256 values. The two exact rejected hashes were reproduced both from the recovered failed-link recipe and during the ordinary observer repeat. Every byte outside the GNU build ID and the eight-byte .rodata section-header entry-size field agreed across all accepted raw alternatives for each target. The exact field offsets, values and hashes of all intervening bytes are recorded in each links file.

The four 619-unit commands selected 102 executables and 110 workspace ELF products. The excluded 617-unit seed commands selected 100 executables and 108 workspace ELF products. All six registered commands had 563 fresh units. All 78 registry ELF hashes were checked, and every workspace product outside the 50 observed links retained its exact per-phase hash. The selected test harness listing was identical in all four applicable commands. No test timing samples are present.

Fresh acquisitions bind every literal argument, the exact ordered argument list, reported and explicit input bytes, default and per-width process records, and full raw native outputs. Original historical exec traces retain only their actual argv and status. They do not contain contemporaneous bytes for the transient symbol objects, GCC resolution files, or the first overwritten e2e objects. Input paths and private arguments in the portable files are represented by SHA-256 digests. The source worker, per-target reports, native process traces and complete ELF files remain retained at their verified private paths. Run `python3 -IB verify.py` to replay the public evidence checks.
