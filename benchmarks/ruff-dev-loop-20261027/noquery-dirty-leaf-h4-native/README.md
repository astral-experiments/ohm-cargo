# Dirty-library release native qualification

Sixty unscored ordinary Cargo commands on an isolated 32-core Linux host used the common frozen Cargo PGO generation and the same first-observer rustc PGO/BOLT image. The initial independent PGO build with differing Cargo dependencies and the earlier development images are excluded.

The test used a real change to `ruff_text_size` at Ruff commit `93526150df078af7dd8fc4226cdcc469539d2001`. For every arm and each of check/build, two independently empty histories exercised the original source, the actual reverse edit, unchanged edited source, restoration, and unchanged restored source. Each dirty command compiled the actual Rust crate once. Both immediate fresh repeats launched zero compilers and helpers in every arm. The explicit-probe control launched a second capability process on each dirty command, six per endpoint. Both baseline and no-query Cargo launched zero such processes. The separate Rust caller, expected missing-method error, source bytes, package metadata and codegen-object gates passed in all arms.

The compressed observations contain all original typed outputs, process counts, argv SHA-256 and embedded object commitments. Run `python3 -IB verify.py` offline.
