A Cargo-built registry proc macro whose Rust metadata and dynamic symbol table remain identical can execute different C code. The registry-only control shows that exposing only full upstream Rust identities lets a stale executable survive two unchanged Cargo builds. The unrelated direct metadata control gives a successful check where an empty build reports E0308.
