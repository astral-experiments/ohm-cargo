# Ruff link-scheduling command and scoring controls

The two Cargo binaries differ by a size tie-breaker for eligible ready native test jobs. Each invocation still runs the stock compiler and native linker. The full command is `cargo +ohm test --workspace --no-run --locked --offline -j8`. The primary experiment adds `--message-format=json` to verify every one of the 619 artifacts after the process exits. The separate plain-output comparison invokes the command as written. Both endpoints measure until the actual Cargo process exits.

The primary controller keeps separate ext4 state for the two batches. Each arm independently settles on an ordinary command, runs a traced qualification, and completes two ordinary warmups. The trace verifies the exact 51 Rust and 150 native argument vectors, accounting for the bytes in three temporary linker input roles. Tracing, executable hashing and the two notebook test verdicts run outside the clock. Each scored JSON command must exit successfully and produce 563 fresh artifacts. The controller saves host CPU, cgroup and memory-pressure observations alongside every adjacent pair.

The plain-output series uses the second stationary batch. The alternating real-edit series uses a separate pair of worktrees. Each edited binary must match the independently empty edited binary. Each restoration must return the original. The published protocol fixes the 96 pairs per host, the independent plain-output check, the 12 edit-plus-repeat pairs, the bootstrap seeds and every acceptance threshold.
