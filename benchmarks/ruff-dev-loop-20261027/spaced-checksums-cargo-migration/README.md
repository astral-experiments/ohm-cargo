# Existing Cargo cache migration with the released -16 compiler

Two real observer workspaces had already been marked fresh incorrectly by packaged Ohm 1.99.0-16. They printed 17 after the physically loaded rlib changed to return 29. The first build after upgrading only Cargo printed 29 in both cases. One retained the literal backslash-space neighbor; the other removed it before upgrading. The target, build directory, crate sources, external bytes, rustc image and encoded fingerprint pathname stayed the same through the upgrade. [Original released compiler and Cargo reproducer](https://github.com/astral-sh/ohm-cargo/tree/dfcbdbd318e5bfa1154ae1537b02df7bdb2d79b0/benchmarks/ruff-dev-loop-20261027/released16-spaced-checksums)

The fixed Cargo keeps the released compiler’s spaced-path observer pending because its checksum could identify the escaped neighbor. Both subsequent no-ops recompiled and continued to print 29. The ordinary filename stayed fully fresh after the upgrade. The additional clean-start matrix covers the same two filename shapes and a spaced path with no neighbor. All controls publish their native program outputs, ELF hashes, Cargo JSON, ordinary depfiles, encoded fingerprints and original/future prebuilt rlibs.

A distinct typed check used a constant array length of 17 and changed the external constant to 29 without changing the pathname or mtime. Stock Cargo returned 0 with all four units fresh; after the neighbor was removed, the first warm check with the new Cargo returned 101 and emitted the same complete structured E0308 as an independent empty check.

The H1 checks use direct physical private toolchains. The release’s Cargo was replaced at the identical pathname while its rustc and standard library remained the same. Two preliminary namespace launchers returned process-permission errors at rustc startup and produced zero eligible artifact rows. The native suite has no timing endpoint or process trace; its empty exec fields indicate disabled tracing. The H8 build receipt records two source-matched Cargo builds, the release-16 SDK, the shared PGO profile and the passing wire-migration unit. A new Rust run-make source test checks the actual rlib digest against the escaped-neighbor digest. Its released parent fails at that assertion. This packet captures Cargo-only migration; updated-compiler controls are a separate experiment.

Run `python3 -B verify.py` for the independent offline checks. Both workspaces and test sources are in `cargo-and-reader.tgz`; `cargo-builder.tgz` contains the Cargo patch, build inputs and unit result.
