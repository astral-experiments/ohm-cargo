# BLAKE3 stream alignment on the released Linux Cargo

The pinned Ruff `ty_vendored` package produces a 5,577,690-byte ZIP and two generated Unicode tables. Cargo hashes those files after preceding structural data in the build-script-result digest, then reads them independently for compilation freshness. In a 313,383,176-instruction plain build, 31,609,352 instructions were attributed to the stream-hashing helper. The binary already contains AVX2 and AVX-512 implementations. The actual profile made 7,162 calls to its AVX2 entry point in Cargo as a whole, consuming 59,076,207 instructions there across all users of the hash. The guest exposes AVX2. [Released Cargo source](https://github.com/astral-sh/ohm-cargo/blob/7caf39914da1e28a67744ecbc963a5f26361474d/src/compiler/fingerprint/worktree.rs) · [BLAKE3 implementation](https://github.com/BLAKE3-team/BLAKE3/blob/1.8.5/src/lib.rs)

Both experimental arms ran the byte-identical released Cargo and the same forwarding read observer. A forwarded its complete first read request. B shortened precisely one 16 KiB request per generated file to reach the next complete BLAKE3 subtree. Both subsequently read every byte through EOF twice. Two unscored positive checks confirmed 182/182 fresh. All 48 scheduled ordinary commands succeeded and preserved both Rust outputs.

The median first-pass time was 6.028 ms for A and 4.156 ms for B. B saved a median paired 1.870 ms and was faster in all 24 pairs. Second-pass time was 3.052 ms versus 3.048 ms, with a paired 0.009 ms increase. The corresponding complete interposed command medians were 218.694 ms and 214.777 ms, with a paired 4.919 ms saving. Those whole-command observations include the identical measurement hooks and namespace launcher. A separate two-host source-product study measures ordinary commands without that instrumentation.

`python3 -B verify.py` checks the two admissions, schedule, requested/reported sizes, all 300 file streams, packaged binary, profile and all per-pair statistics. The fixture-specific runner and hook use the campaign’s already trained 182-unit private state, with the original canonical locations and known digests. The raw elapsed field on the unscored JSON admissions is retained and excluded from the analysis.
