# First package test build after adding TextRange::to_std_range

Ruff added a conversion between its text range and a standard library range in a one-file change. This native experiment uses both sides of that entire edit in a pinned Ruff checkout. Both Cargo versions use the released Ohm 1.99.0-17 compiler and linker. The control uses the observer correctness fix in #261. The candidate adds the scheduler change in #260. [Ruff source change](https://github.com/astral-sh/ruff/commit/61a49c89eb809a238b01616b0a50a0f785702891) · [Cargo scheduler change](https://github.com/astral-sh/ohm-cargo/pull/260)

The setup builds the older library, applies the historical addition, and builds the edited library. A standalone Rust program calls the changed method. The earlier library must reject the call with E0599 and the edited library must return `1..4`. One untouched library build must be fully fresh.

Four independent physical copies of that finished build then run `cargo +ohm test -p ruff_text_size --no-run --locked --offline -j8`, followed by the same command again. The fixed order is control, candidate, candidate, control. The default features select the package’s four ordinary integration harnesses. The worker records successful physical compiler and linker invocations, Cargo’s artifact roster, declared ELF contents and each harness’s `--list` output. It checks that Cargo itself never executed a test harness and that the immediate repeat launched zero compilers and linkers.

The gate requires both candidate runs to save at least two repeated full compilations of those harnesses and two links to their actual destinations. It also requires identical output and listing hashes on every arm and repeat. A passing native result qualifies this specific package for a separate timing experiment. The earlier `ty_server` workspace experiment has its own sample and remains separate.
