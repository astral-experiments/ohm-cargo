# Native file updates with a new or previously trained observer

Use the registered seven-package workspace with a procedural macro that reads a foreign source location and another macro that waits on a deterministic writer. The writer replaces a private two-byte input with an independently timestamped file while rustc is still running. Run every case twice, with an ordinary new timestamp and the original nanosecond timestamp. The current file yields 29. For the builtin controls the initial program value records which bytes the compiler actually saw before the save.

Three acquisition paths are tested. An explicit procedural macro registers the path, reads its numeric contents, then blocks. With `include_str!`, a Rust constant includes the complete text before the later macro blocks. With `include_bytes!`, a Rust constant includes two bytes of invalid UTF-8 before the later macro blocks. The barrier calls the supported tracked environment API with a fixed value to prevent reusing its procedural macro expansion. It registers no additional input path. The source checkout and SDK are unmodified.

In the trained sequence, three successful ordinary builds start at 17. A real caller edit adds a printed line to force a fresh reader compilation. In the first-acquisition sequence the interrupted compiler starts from an empty target. Both sequences finish with two genuine unchanged builds and a separate build from empty on the final file. The new binary must report 29 in that independent control. The runner records every value and whether Cargo considered its caller fresh. It accepts and preserves a stale output, so it can report the failure without suppressing the other cases. No timings are recorded.
