# Initial stopwatch cohort

The first 32 pairs completed every native, archive, and test guard. The median paired edited duration fell 31.88% (95% interval 18.98% to 37.81%, 32/32 favorable). The paired immediate-repeat median was 0.20% slower. The restore-repeat median was 30.49% slower; the reverse-repeat median was 0.016% slower.

The original worker called Python 3.12.3 `subprocess.run(..., timeout=120)` around a child whose stdout and stderr were regular files. Its timed wait polls the child with `WNOHANG` and eventually sleeps 50 ms between checks. The initial cohort is preserved in full to show this limitation. In the second controlled calibration, that polling timer measured eight distinct requested durations between 115 and 157 ms in the same 164.7–165.1 ms band. Use the separately registered blocking-wait cohort for the ordinary Cargo timing claim.
