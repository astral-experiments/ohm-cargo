# Native wall-time calibration with identical parser compilers

Time order moved the result in the first overhead study. This calibration used two separate regular files with the identical release compiler SHA-256. Each of eight blocks first ran the genuine retained parser to change CPU and filesystem state, then ran four independently empty parser compilations. Four blocks used ABBA order and four used BAAB. These are labels for physically independent copies of the same compiler. There are no product comparisons in this packet.

All 32 observed native metadata streams reproduced the independent ordinary reference. The per-block difference between the two labels ranged from −7.18% to +18.12%, with a median of +3.98%. Only four of eight block estimates fell within ±5%. Positions one through four had median elapsed times of 2,450, 2,346, 2,095 and 2,117 milliseconds. This host and block method therefore do not establish a 3% overhead limit reliably on this particular empty-parser command. The preceding 32-pair product result retains its original admission rule and full set of observations. Run `python3 -B verify.py` to verify the exact schedule, image identity, raw timing, resource counters and native metadata. Kernel pressure and cumulative system snapshots are included alongside each child’s CPU time, switches, faults and block I/O. This calibration only evaluates whether the proposed wall-time design is suitable.
