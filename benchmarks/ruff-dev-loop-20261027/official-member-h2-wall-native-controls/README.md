# True typeshed edit on the two installed release packages

The published -16 and -17 Linux packages each made six unscored Ruff member builds. Each history used a separate tmpfs store bound at the same canonical paths. In a private mount of `stdlib/functools.pyi`, both the genuine seven-line historical edit and its exact restoration ran the two expected full compilers and one real Wild link. The freshly linked Rust caller read the expected 18,214 or 18,553 bytes, matching both the input and the decoded embedded typeshed ZIP. Both release images produced the expected outputs on both source states.

On -16 the unchanged commands before, after and following restoration ran two full compilers and one Wild link and left six of 304 units dirty. All three corresponding -17 commands kept all 304 units fresh and ran zero compilers and zero linkers. The stand-alone compiler metadata and the complete cdylib matched the recorded current source in each arm. Both rlibs passed their complete object, metadata and symbol checks. The packet includes original names and SHA-256 digests plus the source-specific contracts for the subsequent trial. The original cold -17 and its independent replacement differ in several raw library artifacts. The currently measured history supplies its own byte expectations.

This packet contains 1,305 per-process native traces from the twelve genuine Cargo processes, the complete Cargo streams and the twelve external caller receipts. Both real binary installations were checked before the commands. Replaying `python3 -B verify.py` checks native compiler identities and full-link counts, every trace hash and native-output contract, and the caller bytes. No timing sample had been collected when the contracts were sealed.
