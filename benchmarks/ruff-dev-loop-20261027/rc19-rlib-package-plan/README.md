# Ruff package archive experiment

The workload is the ordinary `cargo +ohm build --locked --offline -j8 -p ruff_linter` on Ruff commit `1e9287d7654f1dbe4943d67ed5ac5363c9ee2161`. Each edit applies or reverses the full change between that revision and its immediate parent `57d800be552a88751e7ecd06fc87b44714536033`. The release is Ohm 1.99.0-18 on x86-64 Linux with its stock Wild and default Rust flags. Its selected root exposes an actual prior top-level rlib. This package registers a bounded test of a private archive-writing prototype on Btrfs. [Native archive component](https://github.com/astral-sh/ohm-cargo/tree/aa64f341c5500d91339e8b2f465c2b7bc4444257/benchmarks/ruff-dev-loop-20261027/rc19-rlib-current-byte-writer) · [Cargo artifact lifetimes](https://github.com/astral-sh/ohm-cargo/tree/ef15880a76db776ecd61f82eae43d2c8ec60156b/benchmarks/ruff-dev-loop-20261027/rc18-rlib-incumbent-availability)

Each machine uses three independent mutable states seeded from the same stock, warmed filesystem, exposed at the same logical paths. All three receive the same source bytes for the same edit direction. S runs the released tools without the archive interposer. A passes the stock writer's bytes through the interposer to ordinary writes. C attempts a filesystem clone into the stock compiler's private archive temporary, against one explicitly identified prior rlib for the selected package. It compares all current bytes before retaining a matching region, truncates to the correct size, and returns to the ordinary stock publication. The comparison with S includes the cost of loading the prototype. The change does not skip rustc or invoke an alternate linker.

Before scoring, each machine must show a real root-archive rewrite after the edit, an unchanged repeat, a restored source, and a separately empty edited Cargo build. The exact produced linter is linked into a separate SIM222 consumer. The original reports line 1, and the edited input reports lines 2, 3 and 4. A and C must match normal output bytes for the same materialized writer stream in qualification. Wrong, missing or otherwise ineligible prior data and write failures must preserve stock output or error behavior. In the timed C arm, any retained bytes require a successful actual clone and a full comparison with the current stream. A fresh repeat must never invoke the enrolled archive writer. Each machine must qualify the actual compiler and native tool arguments and the artifact roster outside the clock. Every scored triplet must have matching source state and the expected linter verdicts. Warm-versus-empty raw rlib and ELF digests are reported separately. The stock compiler can emit different raw archives from distinct incremental histories.

The primary endpoint is wall time for an edited ordinary Cargo command plus its first unchanged repeat. Each process is timed from launch through exit. Source edits, switching between prepared private filesystems, native consumer verification and scans occur outside the clock. Each machine has 24 fixed triplets across four blocks. In each six-triplet block every permutation of S, A and C occurs once. Each arm occupies each position once in each edit direction. Each direction receives each permutation twice over the experiment. Record all failed or interrupted cohorts. There are no interim effect calculations or optional sample removals. If qualification fails or an external process invalidates a cohort, disclose the failure and requalify before taking replacement samples.

Score each machine separately using the geometric mean of paired C/S ratios, exact two-sided sign test, and all 256 four-block bootstrap draws. Report the raw medians, geometric reduction, 95% interval, sign counts, both edit directions, edited command alone, first unchanged repeat alone, and the two instrumented contrasts. Advance the mechanism only if **both** machines show at least a 1% improvement on the full loop against S, lower 95% endpoint above zero, sign p at most .05, positive effects in both edit directions, positive C/A loop and C/S edited effects, and an unchanged C/S point estimate no worse than a 3% slowdown. A product PR would still require an implementation in Ohm and separate ordinary Cargo measurements of that implementation on new states. Earlier archive-writer timings cannot satisfy this gate.

Run `python3 -IB verify.py` to validate the frozen order and scorer. With a completed raw cohort in the schema consumed by the scorer, run `python3 -IB score.py one pairs.json` or use host `two`. Host one is the independently initialized Genoa machine, and host two is the independently initialized Milan machine. Record the actual machine image, SDK, subject binary, native call counts, fixture bytes, final raw outputs, verdicts and failures with the results.
