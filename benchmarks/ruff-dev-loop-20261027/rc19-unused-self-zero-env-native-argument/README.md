# Integration-link controls without GNU environment overrides

The candidate fixing propagated build-script search directories (`2d04af1e`) still reuses stale native code when two earlier native directories are supplied by Rust source. The crate has zero build scripts. `LIBRARY_PATH`, `GCC_EXEC_PREFIX`, `COMPILER_PATH`, `LD_PRELOAD` and `LD_LIBRARY_PATH` are absent. The compiler and linker are unmodified. These are two separate cases.

**Ordinary Cargo directories.** The test uses a stable external `#[link]` declaration. A valid prebuilt function archive was placed in both the actual `-Ldependency` Rust unit directory and private `target/debug/deps`, then `src/lib.rs` gained a public struct. Neither Cargo setting found the native archive. Both actual linkers returned a native error and both ordinary Cargo invocations exited 101. The kernel argv records prove that neither of those two held directories reached the real linker as `-L`. The prior runs with both directories empty gave the same error.

**Rust source linker arguments.** The fixture adds two literal `#[link(kind="link-arg", modifiers="+verbatim")]` declarations with `#![feature(link_arg_attribute)]`. This is an unstable Rust source feature accepted by the tested Ohm toolchain. No CLI flags, wrapper, injected compiler or driver environment supply these paths. GCC passes the actual ordered private `-L` arguments to stock Wild. The initial Rust test reads 17. Adding an ordinary public Rust struct in its package and inserting a newly earlier archive returning 29 leaves 17 on the candidate. A forced native link and an independently empty target both report 29. Restoring the source while corrupting the earlier archive returns success with the old program, while both forced and independently empty Cargo return 101. With defaults off the ordinary edit reports 29 and the ordinary restoration itself fails with 101. Removal recovers 17 in both settings.

Run `python3 -IB verify.py` for the 22-command compact verification. `source-argument.py SDK EMPTY_PATH --expect skip|relink [--defaults-off]` is the standalone one-package reproducer. `natural-dirs.py SDK EMPTY_PATH [--defaults-off]` independently tests the Rust-only Cargo path case. All fixture files, native archives, caches and aliases stay inside the supplied new directories.
