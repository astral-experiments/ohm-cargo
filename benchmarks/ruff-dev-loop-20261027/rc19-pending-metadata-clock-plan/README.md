# Paired Ruff check protocol for pending metadata dependencies

The primary endpoint is elapsed time for a genuine historical manifest edit followed immediately by one unchanged workspace check. Measure the edited check and the first unchanged check separately as secondary endpoints. Every command runs `cargo +ohm check --workspace --locked --offline -j8 --message-format=json` on the same host and fixed eight physical cores. The release compiler, standard library and stock Wild are identical on both arms. Cargo A is from `235f9228651b74c591e6f62cae4c9b761448dd2d`; B differs only by `b3360c5eda186845b9a2ba6e5330a97c07d4acf2`. Require matching PGO input, builder, top-level rustc arguments and all external dependency bytes across A and B. Record any difference from the historical control ELF.

Use Milan H3 and the separate Genoa machine. Score 32 pairs per host. In each of eight independently shuffled blocks, use each combination of edit direction and arm order once. Run the two visits of a pair adjacent in the preassigned order. A visit restores that direction's independently verified settled build state, applies exactly all 30 changed file blobs, and runs the edit and repeat. Both arms use the same canonical workspace and output paths on a given host. Cargo's private cache namespace can depend on its executable. Seed every participating image before snapshotting. Record the physical tree, compiler and sources; never count first-use compilation as an edit. A host may use per-arm settled donors where an image namespace differs. Prove both donors selected the same workspace, had the same settled semantic state and produced the same external validation. Keep output roots, package sources and build metadata distinct from other experiments.

Open each command's ordinary stdout/stderr files before starting its monotonic clock. Measure process launch through wait with no poll interval, ptrace, timings instrumentation or fingerprint logging. Disable unrelated campaign jobs on that host. Keep setup, selection, source verification, snapshots, content checks and analyses outside command time. Retain all attempts. A failed command, changed input, unqualified donor or broken correctness control stops admission; do not select or rerun a visit on timing grounds. Record every failure explicitly.

Every successful measured check must return zero, end in Cargo's successful build-finished record, select the same complete 510 typed units (by package, target, kinds and profile) and preserve all requested source bytes. Distinct per-direction target test flags should remain distinguishable. Before scoring, verify physical compiler/link counts on unscored controls; never infer native rustc counts from Cargo's dirty artifact count. Compare an applicable incompatible edit with an independent clean compiler and verify recovery. Include a separate ordinary private-body edit and a settled unchanged check as regression controls where exercised. Record the behavior of producer failure, inherited trait changes, absent outputs and release-pin regression tests.

For each pair compute `1 - (B_edit + B_repeat)/(A_edit + A_repeat)`. Report its median and a two-sided 95% interval obtained by resampling whole four-pair blocks 20,000 times. Report the exact two-sided paired sign-flip test on the eight block means of log(A/B), using all 256 assignments. The product performance gate requires at least 1% median primary improvement, a strictly positive interval lower end, and p < 0.05 on each host. Report edited-only and repeat-only results, even if they move in opposite directions. An edited-only slowdown above 3% with its interval excluding zero on either host prevents a default-performance recommendation without further work. Do not pool away a disagreement between hosts. No early success stopping or additions to these cohorts after inspection.
