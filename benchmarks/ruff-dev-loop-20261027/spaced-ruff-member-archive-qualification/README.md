# Native archive names on actual Ruff ordinary builds

An unchanged extra Rust compilation produces new temporary names for its codegen units in an rlib. In the old matched compiler/Cargo pair, new raw archive hashes arose even without a source edit. The first timing design required an exact prior raw hash for every archive. Independent ordinary builds produced previously unseen hashes in both baseline member states before any score. This packet retains the failed raw-vector observations, all witnesses from the new private states and four negative controls.

Both matched arms used independent private clones of the fully trained states. For ty_wasm the diagnostic compared the initial files, two unchanged builds, a seven-line real vendored typeshed change, its first repeat, restoration and the next repeat. For ty_project it checked the initial files and two unchanged builds. After every observation a separate freshly linked program read the expected bytes through the real ty_vendored API. Every ordinary output hash, including every actual rlib hash and all original object names, is retained. Each same-source comparison requires identical object bytes and order, complete ordinary Rust metadata wrapper, matching GNU symbol names and provider ordinals, decoded Rust link metadata in order, and the full header/section structure and other sections of its ELF wrapper. The other products retain their exact SHA-256. The Rust metadata and ELF checks across differently sourced compilers are reported separately by the native companion study.

Corrupting the body of one real codegen object, one GNU index provider, the ordinary metadata, or an object reference inside Rust's link section always changed the measured identity or failed the parser. The resulting comparison describes this fixed ordinary Cargo invocation. Explicit linker scripts can observe original archive names. The packet retains raw identities for that reason. No product code uses this benchmark comparison and no wall clock was taken. Run `python3 -B verify.py` to validate the packet and regenerate the four source contracts.
