# Cargo release inputs for the integration-test completion guard

These locally built Cargo images use the official Ohm 1.99.0-16 compiler, one PGO profile and the same fixed absolute source, target, shared and registry paths. Each of the three release compilations started with an empty target, empty shared build directory and identical, separately copied registry contents. The build order was parent, candidate, then a second independent parent. The training profile SHA-256 is recorded in build-recipe.json. This comparison uses matched locally packaged Cargo binaries. The compiler and its installed SDK come from the distribution.

The third build checks repeatability before the workspace timing study. The individual raw ELF and LLVM-packaged SHA-256 digests appear in independent-verification.json. A packaged parent match is required. The local qualification read all six physical images a second time, checked compiler artifact rosters and full source trees, and verified the ELF section, loader segment, dynamic symbol, version and relocation invariants in each per-arm package receipt. The input Git commit stamp intentionally remains the same in all three arms, so source content and binary receipts authenticate the actual guard.

One post-build reader of the first parent's verbose Cargo log did not recognize a command spanning multiple physical lines in a package description. The Cargo process itself exited zero and emitted both product artifact records. The original log and failed verifier are bound by SHA-256. A corrected reader verified the original complete compiler invocation and the subsequent two arms; it changed no compilation command or image.

The payload includes the exact source patch and registry checksums, full path-to-content hashes of both source trees, per-arm Cargo command and product records, independently verified ELF reports, and SHA-256 digests for the unmodified private logs. The verbose logs remain private. Run `python3 -B verify.py` here to check the packet. Pass an image directory containing the six named Cargo files to additionally check their hashes. This is a release input qualification, with no measurements of Ruff command time.
