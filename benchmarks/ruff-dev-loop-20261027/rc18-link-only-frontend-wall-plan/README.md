# Single-thread frontend for Ruff link-only compiler invocations

This is a prospective test of the full Ruff `cargo test --workspace --no-run` command on Linux. A released-compiler component screen has already run. No full-command timings for this Cargo change have been inspected. The native-link reuse prototype is a separate rejected experiment.

## Subjects and correctness

Use Ruff `93526150df078af7dd8fc4226cdcc469539d2001` and Ohm 1.99.0-18 for Linux x86-64. Control A is Cargo source `7caf39914da1e28a67744ecbc963a5f26361474d`. Treatment B changes only Cargo's automatic frontend-thread default on an invocation that consumes a cached .rlink. Build A and B with the same compiler, optimization settings, profile and logical source path. Record exact input and image digests. Select the Cargo executable at the same SDK path in each private mount. Both arms retain the original released rustc and its packaged Wild. Use the published Cargo binary separately as the behavioral baseline.

Before timing, verify an ordinary unchanged full command in both arms. Require the same 619 logical units, the same 50 native targets, one full ron, 50 link-only rustc, 50 GCC, 50 collect2 and 50 Wild processes. Confirm the change affects the automatically owned rustc thread option only. Check preserved explicit frontend or thread flags, disabled Ohm defaults and full compiles. Reverse Ruff's real notebook offset clamp in the private checkout, run the real link, compare the e2e executable to an independently clean edited build at the identical logical paths, and run the two notebook assertions and 200-entry list. Restore and verify the original program's tests. Record any linker-layout variation separately. Mismatched program behavior or unintended native work disqualifies scoring.

## Full command and sampling

Run `cargo +ohm test --workspace --no-run --locked --offline -j8 --message-format=json` with the canonical private workspace source, a worktree-specific Cargo target and a separate common build directory mapped to the same logical paths. Keep both arms' physically writable state separate. Warm both in each batch. The second batch uses independently prepared state. For each arm require at least two consecutive unchanged warmups producing the expected 619 units and steady fresh counts before sampling. Clear all tracing, wrappers and test-only environment settings from the wall measurement. The toolchain selector, JSON pipes, CPU affinity, job count, machine and Rust inputs are identical. Record host/affinity and verify no other campaign build, trace, archive or timing job is competing on the measurement host. Do not control Wild's worker width or replace its normal jobserver.

The primary endpoint is elapsed wall time directly around the ordinary Cargo process. The private namespace is established before the timer starts. Executable hashing, behavior checks, subprocess instrumentation and JSON parsing take place outside it. Run the 48 adjacent A/B pairs in the fixed order in `order.json`, with 24 pairs in each of two independently warmed batches and twelve AB versus twelve BA orders per batch. Retain every valid pair including unfavorable and slow ones. A timeout, wrong unit count, wrong build result or documented external interruption invalidates a batch. Preserve it and rerun the entire batch in the original order after diagnosing the failure, before interpreting effect sizes. No optional stopping or order changes.

Report both medians, the geometric paired reduction, a 95% percentile interval from 100,000 paired resamples stratified by batch, an exact two-sided paired sign test and the directional result for each batch. Qualification requires both batch estimates positive, the pooled 95% lower bound positive, and an exact paired sign p value at most 0.05. Show all observations whether or not the result qualifies. Per-target component results and compiler instruction counts are supporting endpoints only.

Measure the real notebook change and its first unchanged follow-up separately as a secondary descriptive comparison if the release-matched runtime and space permit it. Do not substitute the secondary endpoint, worker count, or a component interval for the primary result. No change to Ruff enters the product or the measured unchanged workload.
