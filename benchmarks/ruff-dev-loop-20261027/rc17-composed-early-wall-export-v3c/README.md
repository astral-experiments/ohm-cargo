## Operator commands

Run these from a new copy of this directory. Supply the actual manifest SHA-256s and commits obtained by independently reading the published catalog and zero-clock admission. The admission publication must include the exact H5 `admission.json`, `ci.json` and `catalog-publication.json` bytes. The admission also contains the root’s independent witness and provenance, verifier, bootstrap registration and completion. The H2 plan requires a separately issued and independently resolvable terminal release before H5 can score. Use `--native-file`, `--ci-file` or `--catalog-publication-file` if the publication uses different relative names. Each supplied path must be in its independently verified manifest.

```sh
python3 -IB make-pins.py "$CATALOG_DIR" "$CATALOG_REF" "$CATALOG_MANIFEST" \
    --admission "$ADMISSION_DIR" --admission-ref "$ADMISSION_REF" \
    --admission-manifest "$ADMISSION_MANIFEST" --native-verifier-file "$NATIVE_VERIFIER_FILE" \
    --h2-results "$H2_RESULT_DIR" --h2-ref "$H2_RESULT_REF" --h2-manifest "$H2_RESULT_MANIFEST" \
    --h2-terminal-file "$H2_TERMINAL_FILE" > published-pins.json
python3 -IB transfer.py /absolute/new/terminal.json.gz
python3 -IB verify.py /absolute/new/terminal.json.gz "$WALL_PLAN_DIR" \
    "$ORIGINAL_NATIVE_DIR" published-pins.json "$CATALOG_DIR" \
    --admission-results "$ADMISSION_DIR" --h2-results "$H2_RESULT_DIR"
```

## What verification checks

- The active v3c launcher’s `.out`, `.err` and `.exit` for every completed role, the literal generated `job.py` digest, fixed protocol manifest, exact Git refs, QA receipts, both exact-head GitHub check sets and the independent zero-clock approval. The grant pins the fresh CI, accepted catalog and zero-clock admission bytes.
- The stock catalog’s 297 genuine literal recipes, all 9,568 explicit plain/reporting links, 299 ordinary controls, separate two reconstruction receipts, original native commands, complete operand and process commitments, ELF fields and unmodified ranges. Its 50 linked target sets must contain the historical output for each actual occurrence and both previously rejected hashes under their corresponding repeat. Only genuine six-phase width hashes enter those sets. The other 60 workspace files and all 78 registry files keep exact hashes. The separate stock publication supplies the input/path-digest tables and original stock trace commitments.
- The registered order and physical wall command for every slot, independent source/seed/store/image admission, immediate 110+78 product hashes, later 110+78, the two test listings, warnings, all 619 typed Cargo units, 102 test executable paths, every actual native PID and unchanged status. The exporter parses the original successful exec line and exit for each reported physical row and binds its executable, argv and raw trace. Raw Cargo JSON and argument traces retain their original SHA-256s. Public projections omit private registry and foreign path strings.
- The complete 48 true clocks, 24 pair checkpoints, 2,640 cross-arm workspace file comparisons, native result and independently run host verifier. The offline reader replays all 2,704,156 balanced assignments and the registered 100,000 paired bootstrap draws and compares both the recorded statistics and the terminal host verification output byte commitments. A complete but statistically inconclusive result retains its full estimates and decision.
- On a failed admission, score or final verification, the packet preserves the first exception, attempted v3c observations, and all existing still-retained failed-state output hashes. It reports no treatment effect or confidence interval. Derived result text after a failed final verification is commitment-only. If an original traceback includes an outside location, its raw SHA-256 and unchanged safe lines are available alongside individually hashed withheld lines. If even a required checked artifact failed integrity, the verifier can export the rejected evidence with `independent_evidence_valid: false`.

All original host files remain available for authorized private review. A public-safe path digest attests an original file's identity without disclosing its contents. Required verbatim evidence that cannot be publicly represented prevents a successful verification.
