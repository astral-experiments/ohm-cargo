# First full Ruff workspace test build

Cargo #260 avoids compiling and linking the `ty_server` integration test twice after its library finishes. The baseline is Cargo #261. Both arms use the released Ohm 1.99.0-17 compiler and linker. The measured command was `cargo +ohm test --no-run --workspace --locked --offline -j8` on Ruff `93526150df`. Each build started from a separate copy of the same prepared workspace after a real test-source edit. The timer stopped when Cargo returned. Test listing and follow-up build checks ran outside the clock. [Registered protocol](https://github.com/astral-sh/ohm-cargo/tree/f8ee28c60e872a090b4600f473b303738be05029/benchmarks/ruff-dev-loop-20261027/rc17-composed-early-wall-plan-v3c)

Across 24 balanced, randomly ordered pairs, the median fell from 12.601 s to 11.159 s. The geometric mean of the paired time ratios gave a 10.14% reduction (95% bootstrap interval 7.95–12.26%). The candidate was faster in 22 pairs. The exact two-sided randomization p-value was 1.4792e-06. The comparison passed all three registered thresholds. See [individual clock readings](pairs.csv) and [the independent replay](independent-replay.json).

Native traces showed four full rustc processes and 51 Wild links on #261, and three full rustc processes and 50 Wild links with #260. A separate unchanged build after every timed command compiled `ron` and ran 50 links on both arms. [Compiler and linker traces](https://github.com/astral-sh/ohm-cargo/tree/a75e5f17c07081cfcc9fabfcccd7a5022528641b/benchmarks/ruff-dev-loop-20261027/rc17-composed-early-native-results)

All 96 test listings matched. In 2,636 of the 2,640 paired workspace file comparisons, the files were byte-identical. In four pairs the `ty_server` unit-test executable took one of two complete ELF hashes already produced by stock Wild for its inputs. Every first build and unchanged repeat also passed the checks for all 78 registry outputs. [Stock linker output catalog](https://github.com/astral-sh/ohm-cargo/tree/51ecd3a735434901ff53243b6859bedfb3fa43a3/benchmarks/ruff-dev-loop-20261027/rc17-composed-all-links-results)
