# Saving a file after a procedural macro reads it

The macro registered a two-byte file with `proc_macro::tracked::path`, read `17`, and signaled a separate writer. The writer atomically renamed a file containing `29` over the original and then let rustc finish. The two unshipped first-observation implementations both emitted a complete observer record with the BLAKE3 checksum of `29`. The resulting binary printed `17`. Two unchanged builds treated the caller as fresh and continued to print `17`. An independently empty build printed `29`. Both a normal new timestamp and preserving the original nanosecond timestamp produced this result.

An otherwise matched build of the released compiler and Cargo sources emitted an incomplete record on the first compile. Its first unchanged build recompiled the caller and printed `29`. This is a first-acquisition control. The registered follow-up runs the same change after an observer has already settled on the official release. [First-acquisition protocol](https://github.com/astral-sh/ohm-cargo/tree/d0df7863460b1500b264e1c3e687b766d51a72d1/benchmarks/ruff-dev-loop-20261027/noquery-synchronized-inputs-plan-v2) · [First and trained protocol](https://github.com/astral-sh/ohm-cargo/tree/17c7526dc1e5582a2728bcae6ec7ab290610c721/benchmarks/ruff-dev-loop-20261027/noquery-established-observer-plan)

Replacing an external Rust archive after its exported macro supplied `17` gave a different result. All six initiating compilers stopped with a colliding StableCrateId diagnostic. All 18 subsequent programs in those cases printed `29`. The original interrupted experiment is included alongside the revised protocol.

Run `python3 -B verify.py` to recheck the raw Cargo outputs, physical compiler invocations, compiler checksums, file generations and stored native execution output. There are 48 Cargo launches, 42 successful programs and six compiler refusals. The last warm and empty executable in each case was executed and hashed again on its host, for 24 independent end-state replays. These measurements concern correctness.
