# First build after three distinct Ruff parser edits

This study checks whether the two mixed native Rust libraries can reuse work on an edit they have never seen. The timed comparison uses repeated changes and restorations of one parser diagnostic. Here the ordinary and candidate Cargo each receive three complete historical Ruff patches, applied in reverse to the same pinned worktree. They use the same release rustc, an independently cold target and shared build on each arm, and the default workspace command. [Previously registered timing experiment](https://github.com/astral-sh/ohm-cargo/tree/3286437dd9c2f0b898e3f514133e6f5a8809ee83/benchmarks/ruff-dev-loop-20261027/mixed-workspace-runner-h3-v2)

The first edit restores a redundant lexer write when handling pending indentation. The second removes the check for a nonliteral operand after a unary sign in a match pattern. On the pinned Ruff, `case -1**2` and `case -1()` both give the targeted syntax error. The reversed patch should accept them. The third edit restores the previous allocation path for single string literals. Each patch applies in full to `93526150df078af7dd8fc4226cdcc469539d2001`. The plan records their order, input file lists and digests. [Lexer edit](https://github.com/astral-sh/ruff/commit/6e29838d4bd65a2ece1d93d44ce85d8ee0105117) · [Signed-pattern edit](https://github.com/astral-sh/ruff/commit/0ecff877901a0377ad966ffab528488ce872b50e) · [Single-string edit](https://github.com/astral-sh/ruff/commit/ae306a059e3d3d0ce15f6848662407edae4027eb)

For each first occurrence and restoration we will count full rustc invocations, guarded invocations that reuse codegen, full fallbacks, link-only invocations and Wild processes. The next identical command must be fully fresh. The ordinary comparison, native products and the built Ruff's diagnostics test correctness independently. The primary command is `cargo build`. A separate `cargo test --no-run` pair is conditional on the explicit disk-space gate in the plan. The study reports process and output evidence and measures no wall-time effect.
