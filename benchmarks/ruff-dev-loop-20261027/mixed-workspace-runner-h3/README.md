# Ordinary Ruff build and test compilation on the three matched mixed-library arms

The fixed schedule has 18 three-arm blocks for each full workspace command. A uses new Cargo with the previous rustc, B uses previous Cargo with new rustc, and C uses both new programs. Each scored command starts an ordinary fresh Cargo process after returning the full workspace to the original source. The edit reverses the complete three-file parser commit documented in plan.json. The registered analyzer computes four paired contrasts. Qualification, repeated fully fresh checks, restoration and tracing run outside each timing interval.

Each of the six primary targets starts empty on the same ext4 device. Each has its own registry, Rustup selector and shared artifacts, mounted at identical logical paths. Every arm completes one unscored original-to-edited-to-original cycle. The runner records whether each initially trained capsule hit or required a genuine full compilation. Every scored candidate action must then use both guarded jobs. One independent edited target starts empty for each compiler and endpoint and is retired after recording raw products. A separate physically independent copy of each trained C target records every advertised artifact's mode, mtime, digest and independent inode and removes just the two mixed-library cache manifests to force full rustc compilation. The experiment compares both directions with these references. It preserves binary inputs, outputs, per-command receipts, compiler and linker process rosters, raw archive digests and ordinary Rust caller outcomes. Only the temporary references owned by this study are eligible for removal.

The preflight requires 107 GiB free before the first training process. All launches retain at least 25 GiB free, with an additional 12 GiB of headroom before timing. The same two host-local trust settings and eight compile jobs apply to all arms on CPUs 0–23 under the dedicated native lock. A positive registry manifest proof, stable Git index and complete fully fresh inventories are required. Every additional operation runs outside the ordinary scored command.

Records distinguish a checked rustc that still runs the native linker from a full rustc that rewrites its recipe. A hit requires the guarded compiler flag and identical recipe SHA-256 and nanosecond timestamp. Genuine full fallback is checked using a same-state clone. Comparisons check complete shared library bytes, dynamic exports and calls, Rust metadata including private crate identity, the full archive symbol-to-member mapping, and all native codegen payloads. Ordered compiler-generated temporary member nonce changes are tolerated only after checking the precise change to the archive filename table and the link metadata that refers to it. Two normal transitive Rust callers consume the ordered workspace output in both directions. All other native workspace outputs must match with only the predeclared ELF build-ID and .rodata header differences. Failure retains every trace and blocks scoring.
