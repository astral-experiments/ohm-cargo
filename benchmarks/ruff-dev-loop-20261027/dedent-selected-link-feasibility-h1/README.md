# A selected-input link shortcut on a genuine Ruff parser edit

The experimental shortcut saved a median **4.28%** across 12 paired changes to Ruff’s dedent implementation. Seven pairs favored it. The registered criterion required 10 favorable pairs, at least 2% median savings and Holm-adjusted p < .05. An independent four-worker example then showed the shortcut could accept the wrong ELF.

| Experimental Wild mode | Median ordinary command | Paired median reduction from full | Median interval¹ | Favorable pairs | Holm p |
| --- | ---: | ---: | ---: | ---: | ---: |
| Full link | 603.81 ms | — | — | — | — |
| Preselected known output, no input hashing | 557.47 ms | 7.03% | −3.73% to 14.56% | 9/12 | .2920 |
| Hash selected inputs, reuse known output | 594.13 ms | 4.28% | −2.35% to 12.89% | 7/12 | .7744 |

¹ Distribution-free 96.14% median interval, the third through tenth of 12 ordered paired reductions. Tests are exact two-sided sign tests with Holm correction across both comparisons. The number of pairs, schedule, decision and statistics were frozen before scoring. Every observation is included.

Ruff was pinned at `93526150df`. Each of the 36 timed processes ran ordinary `cargo +ohm test --no-run -p ruff_python_parser --locked --offline -j8` on the reverse or restoration of `83a3afc3156d`. No Ruff tests ran. All arms used the same experimental Wild executable from packaged source `e856d81f`, on CPUs 16–23. A dispatcher forwarded the existing release-16 GCC/collect2 linker invocation. The full arm performed the complete link. Both shortcuts still did actual linker file discovery and symbol resolution, authenticated a pre-trained worker-specific ELF and republished it using Wild’s output writer. The selected arm also hashed input bytes for the objects, DSOs and scripts selected in this link. Every measured command checked all three test executables against independent raw references, plus all 41 trivia object payloads and the ordered archive index. These fixture-specific measurements give an optimistic estimate of deployable savings. There were 24 untimed opposite-direction resets and 73 untimed immediate fresh checks. The qualification adds 64 native links covering both targets and all eight widths, four instrumented whole-Cargo edits and five fresh checks. The four traces each show one full trivia compilation, two link-only rustcs, two GCCs, two collect2s and two experimental Wild invocations. The separately run ordinary Rust caller acquired changed behavior, and the shortcut fell back on both source states even with an admitted test target’s output filename. Timing excluded traces, file hashing used for checking experimental outcomes, source edits, resets and no-ops.

The initial captured replay rewrote the two system linker scripts. A 2×2 control showed that rebinding **both** original scripts was necessary to reproduce the selected-input hashes seen by genuine Cargo. The next setup stopped before a native command because its live source for the previously observed one-worker parser executable had changed. The final setup used the previously retained, byte-identical reference. Both failed attempts are preserved with zero timed samples.

The standalone counterexample used the actual packaged Wild at four workers. Adding 8,000 local symbols to the single dormant archive member preserved the three selected objects, their bytes and order, and the sole archive-index entry. It changed the `.rodata` section header’s `sh_entsize` from 8 to 0 and changed the GNU build ID. Both complete native programs still exit 42. The shortcut returned the old complete ELF. Restoring the archive restored the original stock ELF. Wild sizes its input groups from the symbol counts of all parsed members. A selected-object digest alone therefore cannot authorize this optimization, even at a fixed worker count.
