# Timing a finished-producer guard on Ruff test builds

This protocol measures two ordinary `cargo test --no-run` workflows on Ruff at `93526150df`. In the first, a developer selects the full workspace after a test-only source edit, with the normal ty_server library already built. In the second, the workspace starts with an empty target and build directory. Both use eight Cargo jobs on the same 16 pinned CPUs.

The source-matched parent and guarded Cargo use the same PGO data, packaged release-16 compiler and packaged Wild. Two independent builds of the packaged parent produced identical bytes. The treatment changes Cargo's choice to speculate when the library has already finished. The first-selection experiment has 24 adjacent pairs and the cold experiment has 12. Their order, stop conditions, correctness controls and two-sided statistics are fixed in plan.json. The build clock wraps only the ordinary Cargo invocation. Every measured workspace build is followed by an audit of 110 ELF files and final freshness. Three controls for the analyzer exercise a null effect, a slot-order effect, and a known 40% speedup.
