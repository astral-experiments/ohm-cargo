# Genuine foreign-span changes with the FIFO-safe Cargo

This repeats the seven-package native observer experiment on the exact FIFO-safe draft and its matched #253 control. The original candidate saved time on unchanged source and cost time when a genuine foreign span changed. This study measures both effects on the corrected binaries. Full Ruff measurements are separate. [Original fixture, runnable harness and previous result](https://github.com/astral-sh/ohm-cargo/tree/825a3cdd1d19be6a9e86bef9c2942cee57bfa5ac/benchmarks/ruff-dev-loop-20261027/observed-span-holdout)

The unchanged public harness runs the same two independent empty-target references and validates the output and every byte of three native executables after each build. The real edit adds or removes a byte from a private doc comment. An unrelated public macro emits an observable span, and the two affected executables must return the values from the matching empty-target build. Each of 12 blocks measures an ordinary no-op and one genuine edit in both Cargo arms and audits the physical processes separately. The timing includes launching the mount namespace and the Rustup proxy. Four CPUs in a separate local lane are dedicated to this replication. Ruff is being benchmarked on another host.

We report the median wall time by arm, the geometric paired time reduction, a 20,000-draw paired log-ratio bootstrap interval and a two-sided test over the 924 balanced assignments. Holm adjustment covers both predeclared endpoints. A positive reduction is faster for the new Cargo. The unchanged-source and genuine-edit endpoints are both reported regardless of sign. This protocol fixes the subjects and analysis before measuring either endpoint on the corrected pair.
