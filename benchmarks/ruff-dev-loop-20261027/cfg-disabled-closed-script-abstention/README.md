It treats each selected native file as a regular ELF, archive, or narrowly parsed script containing only previously observed absolute inputs. The two small fixtures both keep an unchanged libutil.a script reading nested x86_64-linux-gnu/librt.a. Initially only the normal fallback archive exists. Adding a real earlier object defines ELF symbol ohm_nested_input_marker at 0x97. Replacing it with an invalid script produces the ordinary GCC link failure and Cargo exit 101. Removing it restores the original ELF and zero-test listing. The second fixture substitutes an absolute-only libgcc script while retaining the same nested libutil.a. Another optional tiny scope probe attempted to obtain a positive certificate with a closed GCC input and ordinary libutil. It conservatively failed to certify that fixture as well.
