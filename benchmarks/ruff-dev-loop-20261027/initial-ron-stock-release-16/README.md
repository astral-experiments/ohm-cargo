# First unchanged Ruff test build on official Ohm 1.99.0-16

The unmodified Linux x86-64 installation from the public release built Ruff 93526150df078af7dd8fc4226cdcc469539d2001 in empty target and shared build directories, with both local trust opt-ins unset. Each of three consecutive `cargo +ohm test --no-run --locked --offline --message-format=json` commands reported 619 artifacts, 102 test executables and 110 native products. Real exec tracing of the cold, first unchanged and next unchanged commands found 636/1/0 full compilers, 0/50/0 Rust cached links and 200/50/0 bundled Wild links. Only `ron` recompiled on the first repeat. That recorded 45 input checksums and completed the observer receipt. All 110 ELF files kept their raw bytes between the first and second unchanged commands. The Ruff lint diagnostic, program versions and an ordinary stdlib test were also checked.

The release package, coordinator manifest, installed binary digests, complete per-phase typed rosters and individual ELF hash/entry-width/build-ID receipts are included. The SHA in upstream provenance identifies the Wild distribution artifact. The ELF executable actually invoked was 0d6335808b647d499f3d74993b602e64ff0625206c809bf4913c487eea380cd5.
