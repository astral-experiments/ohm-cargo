# Repairing already-poisoned foreign source observations

Each of two installed Ohm -17 states already held a complete observer record whose executable returned 17 after the input changed. A clean compilation returned 29. The external macro crate, its Rust source and the consumer stayed at the same absolute paths. A genuine earlier edit had recompiled the trained caller, which observed a source snippet before an atomic replacement made it unavailable. One replacement preserved its timestamp.

Each old state was copied twice, verified byte-for-byte including file timestamps, and mounted at its original target, build and Cargo-home paths. The same installed frontend and compiler ran throughout. All four copies first reproduced the wrong fresh executable. The matched Cargo then twice reused 17. Corrected Cargo recompiled the caller on the first and second commands, each returning 29. Independently empty output stores also returned 29 in all four histories. The retained original stores passed their post-run inventories.

The archive records 16 ordinary Cargo commands, their actual compiler execs, completed dep-info and fingerprints, runtime output, eight additional executable replays and all four preserved input histories. This is a correctness check with no wall-time inference.
