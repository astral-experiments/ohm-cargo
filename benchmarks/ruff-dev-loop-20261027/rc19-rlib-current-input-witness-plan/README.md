# Rebuild the selected Ruff archive from the compiler’s own current inputs

Two independent incremental rustc invocations allocate different seven-character suffixes for their current object filenames. Those filenames appear in the GNU long-name table and `lib.rmeta-link`. An ordinary build on either side of the previous trial differed in all ten rebuilt archives, including nine that received no experimental flag. The earlier eight-pair trial ended at its first correctness gate on both hosts with zero timed samples. [Original gate](https://github.com/astral-sh/ohm-cargo/tree/243c497377addad7fe85076c71af9454e48abd94/benchmarks/ruff-dev-loop-20261027/rc19-rlib-in-process-screen-plan) · [Milan originals](https://github.com/astral-sh/ohm-cargo/tree/9fff0f4ed0e2264cb18d7312bc3cf13dcd040970/benchmarks/ruff-dev-loop-20261027/rc19-rlib-milan-first-native)

This is a separate untimed correctness experiment on Genoa and Milan. Use the same private stage1 compiler `ae76b292cb224008e8188a07143797f7a4ce0ec5`, matched release-profile Cargo binaries A `235f9228651b74c591e6f62cae4c9b761448dd2d` and B `0299c77b2ca9707e82bc418976399fdbc75611d8`, and the unchanged Wild 0.11.0 binary. Start both arms from fresh writable snapshots of the retained, read-only historical donor with separate mutable inodes. Use the original locked, offline eight-job `ruff_linter` package build with the genuine three-file change from `1e9287d7654f1dbe4943d67ed5ac5363c9ee2161` to `57d800be552a88751e7ecd06fc87b44714536033`. Run A then B on Genoa and B then A on Milan. Run each edit once and its immediate unchanged repeat once. Preserve every attempted original on any failure. No wall-time observations qualify for performance scoring.

1. Before the edit, authenticate the source, toolchain, shared build root and cargo target, all 248 typed artifacts and the old root rlib. Keep an ordinary open descriptor for the prior target across publication. Compare the same canonical paths, effective environment and eight-core allocation on both arms. Any phase-specific instrumentation must remain outside the toolchain process environment and apply equally to both arms.
2. Trace actual `rustc` process identity, full arguments and exit. Collect the two regular wrapper files `lib.rmeta`, `lib.rmeta-link` and all 256 current `.rcgu.o` inputs directly at the selected compiler’s successful read-only opens before its archive rename. Retain the actual pathname, ordinal, device, inode, length and bytes, and verify the current wrapper encodes the exact same ordered names. Require one selected full compilation and one archive publication, a successful clone from the genuine held old inode into the private temporary archive on B and zero such calls on A. Require all ten known full rustc invocations on edit, none on the immediate repeat, and zero native linkers on either build. Record the option-support query separately.
3. Give an ordinary deterministic GNU archive writer only the 258 captured, read-only named inputs in their compiler order and an empty output directory. Neither finished rlib nor the previous archive may be reachable by that writer. Generate an archive independently with `llvm-ar-18 rcsD --format=gnu`, compare every output byte with the published product, and bind the two SHA-256 digests, sizes and the complete member inventory. Retain GNU names, symbol table, headers, payloads and padding as produced. Fail closed on an unknown or missing member. Demonstrate that changing a real object name or a current input byte gives a different whole output.
4. Check that the held prior descriptor has the same bytes and mtime after publication, the edited archive has a distinct inode, and the unchanged repeat preserves the edited file. Independently link a real caller against the reconstructed and actual rlibs, check both executable byte streams, and execute the four real Ruff SIM222 inputs. The edit must report lines 2, 3 and 4. The clean historical and clean parent references must independently report line 1 and lines 2, 3 and 4 respectively. Authenticate the previously completed clean reference or build the missing reference in a distinct empty directory.

Report a host as passing only after both independently reconstructed archives match their own genuine current publication byte for byte and all gates pass. Preserve any unsuccessful command or infrastructure assertion with its original identity. Stop the host on any mismatch. Do not replace a native sample, use a filename-normalized archive as a reference, start the earlier clocks, or reuse this diagnostic run as a timing sample.
