# Reproducing the Linux linker for Ohm 1.99.0-18

Two Linux hosts rebuilt Wild from the upstream 0.11.0 source archive, the reviewed Unix filename patch and the same digest-pinned Rust image. Both started with a fresh `/work`, used the locked dependency graph and the `dist` profile, and produced the same 10,315,032-byte executable. The SHA-256 was `9de3bdd6675f02e08d687045383c097ab0ef6027c779f153a7823153ecf8445e`. One build ran the packaging shell script directly. A separate harness recorded the equivalent Cargo command, image, compiler version, sources, executable, license digests and modes in the other build. [Wild patch](https://github.com/astral-sh/ohm-wild/pull/44) · [Release manifest](https://github.com/astral-sh/ohm/pull/198)

The stock archive supplied by the published `-17` manifest contained a 10,319,072-byte linker. `readelf` found the same dynamic dependencies, glibc symbol versions through `GLIBC_2.34`, and Linux 3.2.0 ABI note in both executables. The candidate reports Wild 0.11.0 and uses the default fork, plugin, WebAssembly, and Zstandard features. The feature set and ELF inspection do not measure runtime speed.

Run `sha256sum -c SHA256SUMS` and `python3 -IB verify.py` to verify the receipts. To additionally match the manifest, packaging script and full patch to their Git objects, pass `--ohm-git /path/to/ohm --wild-git /path/to/ohm-wild` with both draft heads fetched. On an x86-64 Linux host with Docker, `python3 scripts/prepare-wild.py toolchains/1.99.0/18.json x86_64-unknown-linux-gnu /tmp/ohm-18-wild` rebuilds the executable and checks the pinned digest before staging it.
