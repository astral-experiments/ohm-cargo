# Does a test-target selection edit recompile an ordinary Ruff library?

Ruff commit `b647f3fba81128ae586058b6c0937a3e03c1a997` added one line, `test = false`, to `[lib]` in `crates/ruff_benchmark/Cargo.toml`. The exact line is still present on the study checkout `93526150df078af7dd8fc4226cdcc469539d2001`. Reversing just this change restores Cargo’s default of true. For an ordinary build or check Cargo selects the library either way. The implementation hashes the complete target when computing a unit fingerprint. It separately uses the test field to select default test targets and to serialize the current target in metadata and Cargo JSON.
