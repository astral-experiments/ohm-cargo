# First test build after a TextRange API edit

Ruff added a `TextRange::to_std_range` conversion. The benchmark starts after an ordinary library build has compiled that edit and before the developer first asks Cargo to build the four package test harnesses. It measures the complete elapsed time of one command.

~~~sh
cargo +ohm test -p ruff_text_size --no-run --locked --offline -j8
~~~

The historical edit adds the method to the Ruff checkout at `93526150`. A direct caller rejected the old library with E0599 and returned `1..4` with the edited library. In four independently copied native selections, Cargo #261 (B) started 14 full compilers and 10 actual links. Adding #260 (C) reduced those counts to 10 and 6. Each of the four named harnesses was compiled and linked twice on B and once on C. Both sides selected 11 typed Cargo units and emitted the same six ELFs. All four immediate repeats had 11 fresh units and zero compilers or linkers. Each of those native commands and its copy are outside the wall sample. ## Eligibility

The experiment requires H2, CPU cores 0–7, eight Cargo jobs, the released Ohm 1.99.0-17 compiler and bundled Wild, and both exact release-profile Cargo images. It checks the published source and artifacts plus all eight applicable CI checks for each PR head. The host lock covers the whole study. Native and wall runs use the identical Rustup alias, canonical source, artifact, SDK, HOME, temporary, Cargo home and tool paths. Both arms bind the edited source read-only. The runner checks the source tree, tool digests and the complete SDK tree before and after each stage. ## Verification and decision

The child starts `perf_counter_ns` inside the prepared namespace immediately before launching the ordinary Cargo CLI and stops after Cargo exits. Each selection must exit zero, emit zero diagnostics, and report the four expected executables in ordinary stderr. The worker hashes all 16 output files immediately, then runs each harness with `--list`. Those listings contain zero, one, one, and eight tests. An untouched follow-up in the same state traces kernel process launches and captures Cargo’s typed JSON rows. All eleven must be fresh, with the original paths, features, profiles, targets and artifact sets. All 16 files and four listings must still match. A missing or different product ends the study. No test bodies execute.

The single endpoint uses 24 fresh adjacent pairs, twelve ordered B then C and twelve C then B. The schedule seed is 2026102808051. The reported reduction is `100 × (1 − exp(mean(log(C/B))))`. The arm medians are supplementary. The two-sided exact randomization test enumerates all 2,704,156 balanced assignments with slot positions fixed. A 50,000-draw paired percentile bootstrap with seed 2026102808052 gives the nominal 95% interval. A performance claim requires an ordinary two-sided p below 0.025, a lower confidence bound above 2%, and at least 16 favorable pairs. This package endpoint is distinct from a first full-workspace selection and from time spent running tests.

A separate published admission binds both unclocked preflights before scoring. Only a fully verified terminal series gets an effect estimate. A failed slot retains its private target and every raw clock, output and exception. The final reader reconstructs each interval from the process start and stop in the frozen order. Progress reports contain counts only. Operational commands and evidence formats are in BINDING.md.
