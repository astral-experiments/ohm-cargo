# Actual default cost on the scoped Ruff parser edit

The 12 preassigned pairs compare the ordinary defaults of the two release-profile Cargo images with the same compiler, linker, source and command. R is the #281 parent. F is the #282 candidate. The command covers two integration tests and 147 Cargo units. The candidate still collects scheduling and serialized-link information in this profile.

Median wall time was 2.4561 seconds for #281 and 2.5244 seconds for #282. The median paired change was 2.620% (95% paired bootstrap interval 1.887% to 3.320%). The two-sided balanced randomization P value is 0.021645, and #282 was slower in 12/12 pairs. The median signed pair difference is 0.0645 s. Every timed command was followed by validated native products and both test inventories, then an ordinary all-fresh repeat. Restorations and their checks were outside clocks.

All 96 executable observations matched a complete file SHA-256. Seventy-two matched a traced native ELF byte for byte. The other 24 fixtures comparisons matched a complete ELF reconstructed by changing only the existing .rodata section-header entry size (1 to 0) and recomputing Wild 0.11.0’s 32-byte BLAKE3 GNU build ID. Each version was seen consistently for its arm and source state. An additional checker limited to previously traced raw SHA-256 values rejected the first #281 edited fixture; the registered width-variant check and the independent whole-file reconstruction both passed. The generator remained exactly identical throughout. The frozen enrolment used existing shipped Wild and allowed its known section-header and build-ID variability.
