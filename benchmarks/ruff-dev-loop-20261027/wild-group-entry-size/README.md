# Wild’s worker budget changes an ELF section header

Linking the same three x86-64 objects with Ohm 1.99.0-14’s packaged Wild produced two different executables. At the default input grouping, one linker worker produced `.rodata` with `sh_entsize = 0` and four workers produced `sh_entsize = 8`. Each executable returned 42. Comparing all bytes located every difference within the 32-byte GNU build-ID descriptor and the entry-size field of that single section header. No object, argument other than the worker count, or source file changed. A separate unmodified build from the Wild 0.11.0 tag produced the same two files byte-for-byte.

One input contributes ordinary read-only data and one contributes an eight-byte mergeable constant. The entry point reads both, so `--gc-sections` keeps both. Wild first reconciles entry sizes within each group. It then assigns the group's entry size to the output header. The groups can individually agree and collectively disagree. At one worker, forcing one file per group produced the same eight-byte field as the four-worker link. [Wild 0.11.0 section attributes](https://github.com/wild-linker/wild/blob/e856d81f6683cad80b9fe0ebf1a0c3c403c6fe11/libwild/src/elf.rs#L5593-L5620) · [Group propagation](https://github.com/wild-linker/wild/blob/e856d81f6683cad80b9fe0ebf1a0c3c403c6fe11/libwild/src/layout.rs#L2554-L2570)

The real Ruff runs recorded the same two ELF fields varying on some independent full links. This three-object control establishes a mechanism and does not identify the worker count of an untraced historical link. [Ruff linker and executable comparisons](https://github.com/astral-sh/ohm-cargo/tree/483aa0b9ba35602043c2d748a3a594801b739107/benchmarks/ruff-dev-loop-20261027/parser-doc-linked-products)

Run `python3 -B replay.py /path/to/wild` on x86-64 Linux with GNU `as` to repeat all six native commands. The script executes each result, checks every differing byte and prints the object and output SHA-256 values. For the packaged linker it also checks the complete expected pattern. `shipped.json` and `tag-control.json` are the recorded outputs. There are no wall-time measurements in this fixture.
