# Ruff line index through a native external caller

A separate Rust binary calls `SourceCode::line_end_exclusive` on `"a\nb"`, `"a\r\nb"` and `"a\rb"` and prints all three end offsets. The fixture uses Ruff at `93526150df078af7dd8fc4226cdcc469539d2001` and reverses the entire historical commit `88d851449d2345e11da991794f3e9bfbbd666719` in a private source mount. The external package matches Ruff’s dev profile with optimization level 1, line-tables-only debug info and LTO off. The experiment runs the common PGO Cargo via `cargo +ohm build --offline --message-format=json` with a complete stage-2 PGO+BOLT toolchain. The first parent command seeds the lockfile from Ruff and the other 15 use `--locked`.

Both drivers rebuilt `ruff_source_file` and the external binary with two full compiler invocations on each edit and restoration. All six unmodified repeats had four fresh units and zero compiler invocations. Each arm also compiled both source states from empty, independent Cargo target and shared-build directories. The consumer executable was byte-identical for each source state across warm and clean targets and across drivers. Its SHA-256 was `a13d8ed5644ea31cba581183599d0c50826a9ad25c09f4922afcb08f41c85651` originally and `ffe8479778ad5254e7edb9c69d29c3dda4d0a1edd4efdb443b21f08545e7b7ef` after reversal. All 16 commands succeeded and emitted no compiler diagnostics. Within each arm the producer metadata and API hash also agreed between warm and clean builds. The raw producer archives differed between warm and clean builds on both drivers, and producer metadata/API hashes differed between drivers. Receipts preserve those values separately.

`receipts.json` records all commands, modified source digests, compiler/Cargo digests, dirty units, warnings, output hashes and runtime results. `compiler-arguments.json.gz` stores the original NUL-separated rustc argument arrays by SHA-256, including compiler probes. `replay.py` is the exact machine-specific runner. It uses the reproduced PGO Cargo, stage-2 sysroot and frozen driver paths from the compiler-validation archive and a private registry snapshot. Install those paths and start with empty scratch/output directories to run it unchanged. `Cargo.toml`, `Cargo.lock`, `main.rs` and `source.patch` preserve the complete independent inputs. This control tests linked behavior and conservative invalidation. It makes no timing claim.
