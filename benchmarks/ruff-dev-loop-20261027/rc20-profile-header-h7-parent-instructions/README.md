# Settled Ruff parser builds after a profile-only edit

Cargo #286 excludes a trailing profile-only suffix from the dependency-resolution fingerprint. The comparison uses A, the #284-equivalent release-profile parent; B, the measured #286 implementation; and C, the same implementation with a header scan that can avoid parsing the profile suffix a second time. All three physical Cargo binaries have the same recorded Cargo stamp, native Rust/Wild SDK and release PGO. The experiment compares the immediately unchanged command after a real ordinary Cargo transition in each direction.

| Manifest transition | A parent IR | B parent IR | C parent IR | IR inside B’s extra parse | B parse / parent | C reduction vs B | C reduction vs A |
|---|---:|---:|---:|---:|---:|---:|---:|
| Reverse of historical edit | 281.249M | 283.931M | 281.250M | 186,879 | 0.0658% | +0.949% (6/6) | +0.005% |
| Historical state restored | 281.305M | 283.951M | 281.284M | 194,812 | 0.0686% | +0.942% (6/6) | +0.007% |

Every B observation made one dynamic call to the suffix parser. A and C made zero. We counted the exact instructions executed from the physical caller's indirect call through its return instruction, on that same thread, including descendant library work. The whole-parent comparison includes all application instructions in Cargo and its runtime libraries across its three threads. Every observation has kernel process creation/exec evidence and a paired thread-start/finish ledger. The calibrated instrumentation and system tracer add elapsed time; these are instruction results. Earlier ordinary elapsed results are retained separately in historical-wall.json.

The eligibility decision used six balanced ABC triples per direction with a prespecified 1% median C improvement over B on the restore, at least five favorable blocks, and no median C regression greater than 2% against A on either direction. The result missed the registered threshold for an additional ordinary wall cohort. The earlier 32-pair unchanged restore result for B versus A was −3.75%, with a one-sided lower bound of −7.55%. The instruction experiment measures the extra work by itself. It does not assign a cause to that older wall observation.

The native command was `cargo +ohm test --locked --offline --no-run -j4 -p ruff_python_parser --test generate_inline_tests --test fixtures`. All three roles used physically separate copies of the same authenticated 147-unit warm generation in private Linux tmpfs, bound back to the same logical paths. The original ext4 states and independent cold reference were verified before and after. The primary checks required 147/147 fresh, all 265 files matching the independent reference, no compiler or linker exec, both exact inventories (558 and 1), two directly executed tests and the downstream parser verdict. The independently built proc-macro DSO was opened and returned the same known three-attribute conflict. The previous rejected enrollment had a different cold DSO and diagnostic; it contributed no observations.

The dynamic counter uses a physical same-process owner PID, checks all kernel-observed execs/clones and matches every thread start to exactly one final count. The controlled thread loop contributes four million known instructions. A child-exec and child-thread discriminator excludes those instructions from the scored parent. A separate assembly call with a 3n+4 instruction body window validated both exact return boundaries at two independent lengths in every counter. The raw records, disassembled call and relocation, three source-bound product digests, state correction and historical wall reference are included.
