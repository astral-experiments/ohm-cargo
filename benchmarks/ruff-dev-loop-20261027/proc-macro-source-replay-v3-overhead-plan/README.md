# Ruff parser compilation overhead

This registration measures the cost of correcting cached procedural macro expansion on one real compiler invocation. The command is the native `ruff_python_parser` rustc child emitted by an ordinary full-workspace Cargo build. Both release-matched compilers receive the same command arguments, historical source change, sixteen direct extern files and procedural macro binary. The donor’s libraries are mounted read-only. Rustup dispatch, frontend, code generation, metadata and archive emission are included. Cargo scheduling and unrelated workspace compilation are outside this endpoint.

Each of the sixteen independently ordered pairs per history measures the historical edit once with each compiler. The retained history starts from an independent copy of the arm’s compiled original parser. The empty history uses a new parser incremental directory and the same dependencies. Copies, input verification and diagnostic reads occur outside the measured subprocess. Both endpoints use a one-sided upper bound on the median overhead with a predeclared 3% margin and simultaneous coverage above 95%. Every pair, including any adverse result, is retained. The exact order and tie handling are in the checked-in plan and analyzer.

The unscored admission checks compare independent runs of each arm and history and verify the actual compiler and derive plugin opens. The corrected arm reproduced the full-Cargo training output and both full-Cargo edited metadata digests exactly. The parent’s retained and empty private hashes differ. The candidate preserves that private identity but has a known raw metadata difference across histories in MIR and its constant allocation index. Each sample must reproduce its own history’s qualified native artifact. The earlier full-workspace mixed-library study has a distinct strict raw criterion.

Initial qualification stopped when its trace reader required rustc’s resolved pathname literally in the recorded `execve`. Rustup invokes its verified per-toolchain symbolic path. The replacement qualification requires the exact alias, its target and the target’s SHA-256. The original unscored attempt produced no elapsed measurements.

Run `python3 -B verify.py` to check the schedule, source and binary binding, and every unscored admission record. The scoring worker also requires the immutable admission certificate as an argument and exclusive use of the registered H3 benchmark lane.
