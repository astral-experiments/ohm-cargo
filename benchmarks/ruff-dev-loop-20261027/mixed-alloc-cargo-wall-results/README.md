# Guarded mixed-library relinks on a Ruff parser change

Two fewer full compilations made the ordinary workspace build slower on this edit. The build ran in 5.617 s with the parent Cargo and 6.385 s with the candidate at the median. The candidate's paired geometric-mean slowdown was 14.03%. The 95% interval was 8.63–20.05% and the Holm-adjusted two-sided randomization p-value was 0.000252. Only one of the 20 pairs favored the candidate.

| Ordinary command | Parent median | Candidate median | Paired slowdown (95% interval) | Pairs favoring candidate | Holm p |

| `cargo build` | 5.617 s | 6.385 s | 14.03% (8.63% to 20.05%) | 1/20 | 0.000252 |
| `cargo test --no-run` | 12.543 s | 14.086 s | 9.08% (−5.08% to 24.75%) | 7/20 | 0.269 |

The test-build interval includes both a speedup and a slowdown. The registered performance criterion failed for both commands. Each had ten real edits and ten restorations of Ruff's parser change `3ea20f6161cbf59cb56595dfb634ec24bfa82f0b` on Ruff `93526150df078af7dd8fc4226cdcc469539d2001`. Each arm went first five times per direction. The 80 ordinary commands included Cargo startup. The separate 80 fresh checks verified 501 build units or 619 test-build units, the full artifact roster and the expected Ruff diagnostics. All tests were built with `--no-run`.

Both Cargo binaries ran the same release-profile experimental compiler. During every traced build edit and restoration, the parent ran three full compiles, six link-only compiles and eight Wild links. The candidate ran one full compile and two rustc invocations that guarded reuse for `ruff_wasm` and `ty_wasm`. It still ran six link-only compiles and eight Wild links. For test builds the full count fell from six to four, with two guarded invocations, 62 link-only compiles and 67 Wild links. This comparison isolates the Cargo change on this compiler. The results do not estimate a shipping release or Rust compiler effect.
