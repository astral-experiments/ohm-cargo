# Ruff ordinary builds across an actual typeshed source edit

This prospective timing design uses ordinary member builds on a Linux filesystem whose target directory contains one space. From `ty_wasm` it alternates a real seven-line change in Ruff's vendored typeshed and its restoration. Both matched Ohm subjects build the edit and immediately issue the first unchanged build. It reports the edit alone, that first unchanged command, and the sum. A fourth endpoint measures a warm unchanged `ty_project` build. Each endpoint uses all 24 adjacent randomized pairs, with balanced order within each edit direction. The fixed analysis reports all four outcomes, their multiplicity adjustment and each complete confidence interval. External Rust caller checks and the detailed output validations occur outside all clocks.

Before timing, require the independently retained native qualification, its exact per-arm output contracts, source and image hashes, and an unscored edit and restoration in both cloned copies. Any failed gate keeps the timing attempt from qualifying. The original native states are kept. The native contract must come from that study's complete results and will be bound by a separate immutable ledger entry before any score. The acquisition uses four Cargo jobs and CPU affinity 0–7. These are matched source builds of the canceled and corrected -17 images.
