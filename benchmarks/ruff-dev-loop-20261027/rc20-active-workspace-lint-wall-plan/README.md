# Ordinary Cargo after changing an active Ruff lint

The historical Ruff edit removes three lines from its workspace manifest and enables the Clippy large-stack-array lint. Reversing that edit adds an explicit allowance. This study compares matched Cargo 97e5acfb7 and 70baacdb3 with the same official Rust and stock Wild on the pinned Ruff checkout. The candidate can reuse workspace resolution when only the lint policy changes. The changed compiler option still requires a real build. [Historical Ruff change](https://github.com/astral-sh/ruff/commit/3edca130e22b2aba1d0cfe263e3f6a6679e166cc)

The three endpoints are checking the ruff_text_size library, building the library, and building its serde integration test without running it. Each eligible endpoint has 32 independently allocated pairs split equally between reversing the historical change and restoring it. Each direction has eight pairs in each arm order. The combined edit and first unchanged duration is primary for each endpoint. The shared three-test Holm correction, all confidence intervals, and the 3% and 5 ms repeat bounds are frozen in protocol.json. Each trial starts over a read-only donor that has seen exactly one manifest state. Both images face byte-identical initial Rust artifacts.

The native gates require the actual current compiler arguments, true linker executions, independently empty same-source references, and the unchanged caller verdict. Check must accept a valid consumer and reject an invalid one with E0599. Build must link a byte-identical caller returning 17 29 12. The serde test ELF and complete test inventory must match and all three tests must pass. Library archives retain both full raw hashes and an ordered-content witness for compiler-generated member-name variation. The native trace, logging, hashing, setup and consumer witnesses are all outside the ordinary command timers.

Run `sha256sum -c SHA256SUMS`. The registration digest sent before timing is the SHA-256 of protocol.json. The timing worker and portable paired estimator were also frozen before the first sample. All original files and role exits remain available for verification in the result component.
