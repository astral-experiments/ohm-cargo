# Consistent native-to-check dependency graphs

On unmodified Ruff 93526150df, full workspace build followed by check failed on the source-matched baseline with a pep440_rs StableCrateId collision. Corrected Cargo built 501 units, then checked all 520 workspace units successfully. Of those, 154 were already fresh. Both immediate check repeats were fully fresh, as was the subsequent 501-unit native build. The independent empty-cache workspace check produced identical diagnostics. The same corrected #233 compiler, byte-identical frontend, linker and PGO input served both Cargo binaries.

Across 12 independent randomized pairs of fresh private caches, the baseline failed to typecheck the four-package diamond 12 times and corrected Cargo succeeded 12 times. The two-sided paired sign test on command success gives p = 0.0004883. The unrelated dependency's native metadata retained the exact same path, bytes, inode, ctime and mtime, and no compiler launched for it during the corrected check. The captured outcome is correct completion. A failed baseline cannot establish a comparative elapsed-time speedup.

The original plan and seed, exact compiled source patch, binary digests, all 24 outcomes, compiler execution traces, full-workspace receipts and two separately retained observer failures are in `qualified.tar.gz`. The preliminary assertion looked for an .rlib in Cargo check JSON. Cargo returned the existing native .rmeta instead, at the same path as the preceding native build. The final guard directly checks its identity and records launches. No pilot trial contributes to the 12 pairs.

The `suite` directory has the checked-in regression, independent mixed and pure library controls and the disabled shared-stages type mismatch. The six existing Cargo suite controls passed on both arms with identical defaults opt-outs. Running those historical snapshots against a packaged compiler with defaults enabled gave the same three stderr differences on both arms. The real published release, registry fixture, intentional type-error diagnostic and disconnected graphs are independently documented in [the portable fixtures](https://github.com/astral-sh/ohm-cargo/tree/dddd251fe5543f08166445159bf7d86d7e47fed4/benchmarks/ruff-dev-loop-20261027/native-check-fixtures).
