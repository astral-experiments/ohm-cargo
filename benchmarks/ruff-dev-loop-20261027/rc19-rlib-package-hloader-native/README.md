# Ruff linter archive writer on released Ohm

**The whole-Cargo comparison stopped before taking any wall samples.** Released Cargo puts 185 of the 248 declared build artifacts in a different cache when a process sets `LD_PRELOAD`. The ordinary historical edit rebuilt 10 units. First running the same source edit through either write interceptor rebuilt 241. All 248 units were fresh on each immediate repeat. Comparing their times would mix cache routing, compiler work and archive writes. [Prospective package protocol](https://github.com/astral-sh/ohm-cargo/tree/cd2dee0bcc68a304cf7c0c68ddd82db7e3828e2a/benchmarks/ruff-dev-loop-20261027/rc19-rlib-package-plan)

This was the registered x86-64 Linux Genoa machine, with eight CPUs in the worker's affinity mask, an unprivileged private Btrfs image, and the public Ohm 1.99.0-18 Linux toolchain. The ordinary workload built `ruff_linter` offline with eight Cargo jobs after applying or reversing the complete change to Ruff's private f-string helper in commit `1e9287d7654f1dbe4943d67ed5ac5363c9ee2161`. Its parent is `57d800be552a88751e7ecd06fc87b44714536033`. Off-clock qualification requested Cargo's JSON artifact messages, and two stock transitions had external syscall tracing. The proposed implementation was a private libc hook for the shipped Rust compiler's GNU archive writer. [Ruff source change](https://github.com/astral-sh/ruff/commit/1e9287d7654f1dbe4943d67ed5ac5363c9ee2161)

## Why the work changed

Cargo 7caf39914 treats a nonempty `LD_PRELOAD` as compiler loader injection. That flag disqualifies the compiler from its trusted shared registry cache. On this fixture, 340 declared file paths moved from `shared/debug/build/registries` to `target/debug/build/workspaces`. Every moved path retained its original unit suffix. The 63 remaining artifact rows kept all their declared paths. `routing.json` gives each matched target's original and actual paths relative to the owned state, along with all six raw Cargo message commitments. `release-cargo-source.json` binds the applicable source lines and complete file digests to the released commit. [Loader policy](https://github.com/astral-sh/ohm-cargo/blob/7caf39914da1e28a67744ecbc963a5f26361474d/src/compiler/mod.rs#L174-L185) · [Trust decision](https://github.com/astral-sh/ohm-cargo/blob/7caf39914da1e28a67744ecbc963a5f26361474d/src/compiler/build_runner/compilation_files.rs#L543-L552)

In the ordinary edited and restored archives, 77,408,976 native payload bytes and the 9,251,912-byte GNU symbol index are identical in place. Those two sums establish 86,660,888 equal-position bytes. All 256 member names, the GNU long-name table, wrapped Rust metadata and link metadata changed. An in-process compiler writer handling this real 10-unit transition could compare the corresponding ranges of an explicitly supplied prior archive. The current writer would still have to generate and authenticate every byte of the output. The precise avoidable write volume depends on the chunk boundaries and where other changed bytes lie. The 540 stock writes ranged from 60 to 15,165,872 bytes. On one externally traced restoration they occupied 153 ms inside `write` and 292 ms elapsed from archive open return to close return. These are traced component observations.

In both conditional transitions the actual wrapped metadata payload shrank by exactly 24 bytes relative to the stock seed. Every native payload remained byte-identical and all 256 moved 24 bytes earlier. The hook retained only 10,787,212 of 101,879,280 bytes. It issued real writes for the remaining 91,092,068 bytes. The same result applied in the restore direction against its own original stock seed. These figures describe the instrumented cache domain.

## Correctness observations

- For each of four real qualified compilations, the probe retained a separately materialized same-invocation reference stream. Full SHA-256 of that stream equaled the hashed unit archive and the published package archive. Observe and a malformed prior each used ordinary writes, while both eligible directions successfully cloned. The open old stock archive and held hardlink preserved their old bytes across publication. All 248 declared artifacts were fresh on immediate repeats, and the enrolled writer produced no repeat log.
- The separately compiled Rust program calls the actual `ruff_linter` SIM222 rule on four f-string cases. Stock, observe, conditional and malformed-prior builds all returned lines 2, 3 and 4 on the edited source. Restoring the source returned line 1. The independently empty edited state rebuilt all 248 units and returned exactly the same three edited rows. All warm edited caller binaries hashed to `38ac0895…`. The empty-state edited caller ELF hashed to `aa2d717e…`, with the same stdin, stdout, exit status and stderr digest. Both distinct raw ELF digests and the distinct raw archive digests are retained. This oracle reads the linter through its Rust API. It does not inspect a typeshed ZIP.
- The 22 small native controls used real GNU archives and C consumers. They covered invalid, absent, short, long, directory, FIFO and symlink incumbents, a failed publication, genuine short write and `EFBIG` under a 512-byte limit, and a single actual `SIGXFSZ`. Synchronized same-inode writes changed the mapped input in both directions after acquisition while preserving size and mtime. The fallback output and reference used the one captured input. The earlier logger produced two signals at the size limit. The corrected logger avoids regular-file reporting under that limit. The first old-archive hardlink test also stopped at `EXDEV` before an edited compile. Both initial failures appear in `native.json`.

## Reproduction

Run `python3 -IB verify.py --selftest` and `sha256sum -c SHA256SUMS`. The verifier rechecks the source and input commitments, member positions, complete participating archive/caller hashes, recorded system call outcomes and cache-route change. Four negative tests mutate a reference hash, a relocated path, a member offset and a consumer verdict.

On Linux with GNU cc/ar, run `python3 -IB reproduce/run-small.py /path/on/private-btrfs/new-directory` as an ordinary user to build the same helper source and repeat the 22 native controls. The published registry records contain target names and relative artifact paths. The larger local strace, full archive/metadata, consumer executables and compiler outputs stay in the private study store under the digests recorded here.
