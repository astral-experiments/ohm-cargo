# Independent released-package timings for an unchanged Ruff member build

On a second Linux host, the ordinary `ty_wasm` build took a median **1.675 s with -16 and 0.403 s with -17**. The paired reduction was **75.59%** (95% interval **70.88–79.35%**). The released -17 package won all 12 randomized pairs. Two of the 924 balanced allocations were as extreme, giving two-sided p = 0.00216.

This test used the actual downloaded -16 and -17 Linux SDKs, an unspaced SDK path, a target directory with one space, the real Ruff member at commit `93526150df078af7dd8fc4226cdcc469539d2001`, independent private stores on the same tmpfs device, and 4 Cargo jobs on CPUs 0–7. Only uninstrumented `cargo +ohm build --locked --offline -j4` was timed. Both states genuinely compiled a seven-line typeshed edit and its restoration before timing, and separately verified callers read both source states. The 12 balanced adjacent pairs and numerical decision rule were registered before collection.

The terminal native commands confirmed the old package was still compiling `ty_vendored` and `ty_wasm` and running one real Wild, while the new package kept all 304 units fresh with zero rustc and linker processes. All 24 timed commands passed the full per-source product checks and all 26 caller commands returned the expected complete bytes. The unchanged -17 commands retained every native product's raw hash and all tracked stat fields. The final cdylib differs between these two distributions, as recorded in the original native study. Each release is checked against its own verified product.

This replication measures the end-to-end difference between released binaries. The separate source-matched experiment measured 76.61% less time for the first unchanged build after an edit, with a 6.16% slowdown on the edited command itself. This secondary trial only timed the warm unchanged command. The unscored source-edit trials are in the separately bound qualification.

Run `python3 -B verify.py` to recompute the 24 clocks, every output and caller check, the 155 terminal native traces and the paired estimate. `observations.tar.gz` contains the original subject, clock, product, caller and native-process receipts and a byte-level inventory.
