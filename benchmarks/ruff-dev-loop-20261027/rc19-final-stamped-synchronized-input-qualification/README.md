# Final Cargo and Rust on previously stale programs

Linux release-profile Cargo `34dad66fd2ac823bfb02c2c4a4bab02fb5ac4d31` reported its genuine source version and date. The private SDK used independently source-built Rust `5e3de497d41f4d4fa98fce3082ea43076779de5d`, its matching standard library and the unchanged shipped linker. Across 26 independent histories, 140 ordinary Cargo build or check invocations used these physical executables. Each affected caller ran through rustc on the repeat, second repeat and independent clean command.

The twelve file histories cover a tracked procedural-macro input, `include_str!` and binary `include_bytes!`. Each tested both a first-time and previously trained reader, with a real rename to equal-length input at a newer or preserved timestamp. Cargo’s original in-flight executable printed `17` after the compiler had already read the old input. Both subsequent builds and an independent clean build printed `29`. The historical Linux -17 Cargo returned `17` on trained cases after the file had changed. [Historical -17 executions](https://github.com/astral-sh/ohm-cargo/tree/55fc99a09e3bb529294de08dd73f372abae22dd3/benchmarks/ruff-dev-loop-20261027/noquery-established-observer-results)

The binary histories change a loaded procedural-macro DSO or an actual standalone Rust metadata input. Current and preserved mtimes are covered. A typed macro control keeps the Rust source, dynamic-symbol section and Rust metadata section byte-identical while the C-backed implementation changes its output from the accepted unsigned type to an invalid signed type. The initiating check succeeds. Its two unchanged retries and the clean check produce the same structured `E0308` diagnostic. Whole-program outputs were reopened 36 times and every captured sample is `29`. All 24 changed-input type errors match their respective clean diagnostic. Each overlapping compiler that saw conflicting Rust crate identities reported its collision. [Binary-input protocol](https://github.com/astral-sh/ohm-cargo/tree/d94e602e0f3b0eb357e9a386e3fc27971727937b/benchmarks/ruff-dev-loop-20261027/synchronized-compiler-inputs) · [Fixed-reader fixtures](https://github.com/astral-sh/ohm-cargo/tree/e41b8d460f8f2607e572587c01ec56708bb2ddb4/benchmarks/ruff-dev-loop-20261027/cargo-binary-input-mitigation)

Two historical fixture assertions still reject the newer compiler after its seven commands complete. Each expected the initiating standalone-metadata check to succeed. That mutation changes both private and public Rust hashes in the qualified compiler, and the real initiating error reports colliding stable crate IDs. Each warm and clean check then reports the expected `E0308`. The receipt retains both rejected assertions, every compiler event digest and the final outcomes.
