## H5 storage and isolation

The XFS seed is never used as writable trial state. Admission checks XFS and a genuine same-device FICLONE write-isolation probe. It binds either reflinks for every slot or physically independent full copies for every slot. A size/mtime shortcut cannot satisfy the restore check. Each clone is verified against the SHA-256 tree, including path, file bytes, mode, uid/gid, nanosecond mtime, symlink target, xattrs and internal hardlink topology. Every regular-file inode differs from the seed's. After copying, syncfs outside the clock gives each subject the same warm-read, completed-write policy. Full copies cost 48 times the seed's regular-file bytes in copied data over the series, plus physical reads for verification. The admission reports the actual number using the seed census. Only one temporary copy exists at a time. Require space for that full seed, a 6-GiB output allowance and a 32-GiB reserve before every restore, even on reflink-capable XFS. Successful slots release only their own verified state. A failed slot retains its entire state and receipts. The same H5 native-measurement lock serializes admission and scoring, and a separate grant must verify no competing host study. Benchmark commands retain the full session-output/exec evidence privately.

The local analyzer has null, slot-only, 40% gain, and slowdown controls. The local guard fixtures reject a missing observer, missing or extra e2e jobs, changed extern, failure, unknown ELF, missing product, altered text, changed warning and same-size backdated file. Historical release-16 native diagnostics and both genuine first-pair human outputs independently checked the warning reader.
