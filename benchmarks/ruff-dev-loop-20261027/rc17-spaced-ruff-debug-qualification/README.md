# Why the original Ruff timing trial stopped before its first clock

Cargo’s shared build cache puts artifacts from different compiler installations in distinct directories. The first timing trial required the same full artifact paths across the two installations. It stopped on that assertion before either endpoint ran a measured command. After matching the installation directory in typed output filenames, all 303 package units and 619 workspace units had the same targets, profiles, features, output basenames, crate hashes and diagnostics.

All four package binaries matched byte for byte. In the workspace, 106 of 110 native files matched. The remaining four were the normal and test forms of Ruff and Ty. A bytewise comparison across the entire ELF found differences in the GNU build ID and three DWARF sections. Every byte of the executable code, runtime data, debug line tables and all other sections matched.

For each of the four binaries, jemalloc records its compilation directory once in the DWARF string table. Each installation has a different 16-digit compiler namespace there. GNU readelf decoded all four pairs without warnings. After resolving string offsets and substituting the two exact build-directory spellings, the complete decoded debugging attributes, macro records and full sorted string inventories matched. The two raw debug layouts remain distinct.

The original worker and its zero-clock rejection are preserved. Run `python3 -B verify.py` to check the native identities, full-file difference attribution, typed path tests and debug reports. The raw native files remain on the qualification host.
