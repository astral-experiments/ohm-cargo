Released Ohm Cargo `7caf39914d` and its qualified successor `235f922865` select ordinary library builds and checks by target kind. They select default test targets using the separate `tested` boolean. Rustc gets its test mode from the selected compile mode, and Cargo derives the compiler metadata hash from the target’s name and kind. Cargo nevertheless hashes the full target, including `tested`, in `calculate_normal`. Comparing that fingerprint with an existing one can produce `TargetConfigurationChanged`. This predicts a redundant non-test compilation after editing the test selection metadata. The prediction still requires a physical Cargo run. [Target selection](https://github.com/astral-sh/ohm-cargo/blob/7caf39914da1e28a67744ecbc963a5f26361474d/src/ops/cargo_compile/unit_generator.rs#L179-L189) · [Ordinary-unit fingerprint](https://github.com/astral-sh/ohm-cargo/blob/7caf39914da1e28a67744ecbc963a5f26361474d/src/compiler/fingerprint/mod.rs#L2716-L2725)
