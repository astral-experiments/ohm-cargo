# Change an input while an observing Rust compiler is still running

The existing seven-package fixture acquires source information from a foreign macro span. One new procedural macro stops after consuming the numeric token 17 and signals a separate process. That process atomically replaces a private input with a same-length version encoding 29, then releases rustc to publish the result. In one mode the numeric token came from a macro in a real `--extern` rlib. In the other, the macro reads a file registered with `proc_macro::tracked::path`. The input is replaced in one run with its current modification time and in another with its original nanosecond time. Neither path belongs to the toolchain or a Cargo output directory.

For each native pair, compare the authentic first binary, two unchanged invocations and an independently empty native build. Store every compiled binary's hash and output, compiler depfile and Cargo fingerprint, input identities, Cargo JSON and process trace. The initial binary must print 17 and the independent post-change binary must print 29. A subsequent warm binary printing 17 would be a freshness failure to investigate before recommending first-observation reuse. These runs do not estimate performance.
