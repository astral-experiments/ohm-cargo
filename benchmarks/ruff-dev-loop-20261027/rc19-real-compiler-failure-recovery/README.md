# Build recovery after real compiler failures

Published Linux Ohm 1.99.0-18, the Cargo revision selected for -19 and Cargo #279 all rebuilt the dependent on the first command after reverting a failed upstream build. The first-retry executable and an independent clean executable had identical SHA-256 values and printed `17`. A subsequent valid upstream change printed `29`. The comparisons used the packaged -18 compiler and stock Wild. Each arm used separate private build roots and compared binaries at its own canonical paths. [Cargo #279](https://github.com/astral-sh/ohm-cargo/pull/279)

Three histories used actual compiler processes. One included an assembly directive that deliberately failed code generation. Another held the upstream assembler in an include until the dependent Cargo library had committed a new 16-hex fingerprint, then supplied the same deliberate error. The third kept the same assembly directive on every source revision and changed only the value of a public constant. After witnessing the dependent’s commit, the harness sent SIGKILL through a pidfd to Cargo’s exact upstream rustc child. The first revert after each history rebuilt the provider library, dependent library and binary. The next build kept all three fresh.

These nine histories cover 63 Cargo commands and 54 reopened executables. All six deliberately ordered interruptions or failures observed a new dependent fingerprint. Two exploratory controls completed without reaching their requested interruption. A stable assembly body reused its old codegen unit in one. The native build did not invoke the metadata timestamp hook used by the check-mode witness in the other. Their output hashes are retained separately.

A different checked-in Cargo test wraps compiler notifications, makes its upstream report failure after the parent commits, then sees E0460 on the first reverted build. Its regression is independently bisected. The ordinary runs here bound the demonstrated scope of that failure. [Checked-in recovery regression](https://github.com/astral-sh/ohm-cargo/tree/6871b1f22ccfb517cfe84e727f1cc7afdfc23c17/benchmarks/ruff-dev-loop-20261027/rc19-failed-producer-revert)

Run `python3 -IB verify.py` and `sha256sum -c SHA256SUMS` to verify the packet. The most constrained ordinary Linux test is reproducible with `python3 -IB replay.py /absolute/ohm-sdk /absolute/new-empty-path`. It creates only private fixtures and signals its own verified child compiler.
