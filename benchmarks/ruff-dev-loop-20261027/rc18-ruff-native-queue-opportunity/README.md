# How long Ruff links waited in released Ohm

The published Linux `1.99.0-18` Cargo dispatched smaller ready native jobs while larger ready jobs of equal priority waited. All 50 real native links can be joined to stable target identities. The `ty_server` e2e executable was 226,518,976 bytes. It waited at least 2.060 seconds behind 36 smaller jobs. Its similarly named unit-test harness waited at least 1.869 seconds behind 29. This was a whole-workspace `cargo +ohm test --workspace --no-run --locked --offline -j8` on Ruff `93526150df078af7dd8fc4226cdcc469539d2001`. A focused invocation of `-p ty_server --test e2e` on the released toolchain was already fresh. The installed Cargo's scheduler trace contains 689 registered jobs and 29,419 dependency edges. All 50 native jobs had priority 200 and required the full completion of every direct prerequisite. To avoid counting time when a job might still be blocked, take the *next dispatch* after the last prerequisite finished. Starting there, 43 of the 50 jobs waited behind one or more smaller, equally ranked jobs, yielding 457 ordered pairs. The 134,628,441-byte source log is represented by its SHA-256 and a portable 50-row projection. The second machine's private diagnostic Cargo tracked pending-queue insertion and actual jobserver-authorized dispatch directly. Across three executions, it found 511, 458 and 541 smaller-before-larger pairs. Instrumentation affects the timings here. A separate invocation traced each real process from `exec` to exit and authenticated the stock Wild, GCC, collect2, rustc and all 50 actual ELF files. The Pearson correlation between prior ELF size and native linker duration was 0.984. Four more released invocations on two independently heated stores reported correlations of 0.876, 0.984, 0.973 and 0.987 between ELF size and Cargo's per-target duration. Each reported 619 compiler artifacts with 563 fresh. The ordinary timings view omits transitions through already-fresh prerequisites, so these four runs establish a cost signal. The scheduler traces establish when jobs became eligible. No invocation here estimates the whole-command benefit of changing the queue.
