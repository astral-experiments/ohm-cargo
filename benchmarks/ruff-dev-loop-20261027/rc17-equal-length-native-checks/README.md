# Native reader with a same-length, backdated archive replacement

The released Linux Ohm 1.99.0-16 executable still printed **17** after the external library changed to return **29**. Cargo reported the reader fresh. An independently empty target printed **29**. The existing Cargo target repaired itself on the first invocation with the corrected Cargo, with either the real decoy kept or removed. A fresh fixed Cargo and Rust pair compiled once after the change and printed **29**. Its unchanged repeats compiled zero readers in the spaced, spaced-without-decoy, and ordinary controls.

This fixture compares a native library at `input space/libescape_fixture.rlib` to a separate real library at a directory literally named `input\ space`. Both library builds use the exact same source spelling, compiler arguments and output pathname. The fixture copies their bytes to the two test paths. The genuine library starts at 17 and the decoy already contains 29. The final mutation writes the future bytes in place and restores the exact nanosecond timestamp. All 24 native cases verified a changed SHA-256 and identical inode, modification time and byte count. Across separate outputs the archive sizes were 7,528–7,568 bytes.

The 132 ordinary builds produced and ran 132 native readers. The other 16 Cargo commands check a Rust const against the extern and compare the full error to a separate empty target. They yielded the expected E0308 after the edit on the fixed pair. On a genuinely poisoned old cache a pre-migration check succeeds and the immediate corrected check reports the same E0308 as clean. The old Rust compiler paired with the corrected Cargo conservatively recompiles ambiguous names on every repeat. The fixed Rust compiler with either Cargo makes the unchanged three naming controls fresh and still notices the real edit. The permanent Rust test passed separately on the -16-source backport.

The RC17 observations use independently built matched PGO/BOLT tools on the canceled RC17 source, with one compiler frontend and its existing SDK. The -16 comparisons also include the actual published tools, a release-profile backport to the -16 Rust source using the same donor frontend, and Cargo built from the -16 source with the path correction applied. Each target, Cargo home and shared directory was private to its test case. Native commands ran on four Linux cores with tracing outside a timed study.
