## Pairing and analysis

The frozen order contains exactly 32 adjacent B/E pairs. In each consecutive four-pair block, the four parent/child × BE/EB combinations occur once, shuffled with seed 0x280BEE. Each pair has one source state, with independently restored input for each arm. Both sources are the unmodified, historically checked-out Ruff trees at 716260bf10d7 and 2d6ce561250a. The original tree transition changes 30 files in this 47-default-member workspace. The unchanged check stays on the selected source throughout its visit.

For each pair compute (E minus B) divided by B in integer nanoseconds. The estimator is the median of these 32 relative differences. Resample eight intact four-pair blocks with replacement 50,000 times, using seed 0x280051 and linear percentile interpolation at 2.5% and 97.5%. Declare noninferiority only when the upper endpoint of this two-sided 95% interval is strictly below 0.03. Per-source medians and unpaired medians are descriptive.
