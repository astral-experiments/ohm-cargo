# Why full Ruff compiler rows differed between the two rustc images

The whole-workspace study's first native runtime rejected its literal 619-row Cargo product roster before recording any wall times. Cargo puts the two compiler installations' outputs under different 16-digit namespaces. On the same older compiler, the old and candidate Cargo produced identical raw rosters and all 110 cold ELF hashes matched. Across the two compiler images, changing the observed directory component in typed filenames and executable paths reconciled all 619 Cargo rows for the old pair, the old-compiler crossover and the cooperating pair. The saved early snapshot covers those three original histories. A separate terminal packet covers all four.

106 of 110 cold native ELF files matched across the old and cooperating pair. The exceptions were the main and test binaries of Ruff and Ty. SHA-verified copies from the two crossover builds reproduced all eight original reference hashes exactly. An independent machine verified every ELF byte outside the GNU build-ID descriptor, the recorded .rodata header cell and three named debug sections. The .rodata header cell and all section metadata also matched in these eight files.

For each pair, all raw code, runtime data, debug line tables, program headers and padding matched. The four differing section payloads were .note.gnu.build-id, .debug_info, .debug_macro and .debug_str. The tikv-jemalloc-sys build records its actual directory once in each DWARF string table. GNU readelf resolved 58 DW_AT_comp_dir references to that string per file. After resolving actual string offsets and substituting the two exact directory names, every decoded DIE, macro record and complete string inventory matched. The scanner also committed to the exact byte string resolved by each real strp offset.

Run python3 -IB verify.py for the compact evidence. The file decode.py records the full byte and debug checks when the eight native inputs are available. The earlier failure and the [original prospective performance plan](https://github.com/astral-sh/ohm-cargo/tree/679c93366ba5d9a80361da08a6ab27e380ccac42/benchmarks/ruff-dev-loop-20261027/noquery-full-h4-plan) remain separate.
